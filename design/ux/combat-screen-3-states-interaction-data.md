## States & Variants

| 状态 / 变体 | 触发 | 画面变化 |
|---|---|---|
| **入场转场** | 野外触碰敌人，场景切入 | 转场效果后各 UI 分层就位（顺序见 Transitions & Animations）；中央框显示首条战况文字（如"✦ 遭遇了 猎手！"） |
| **锁敌预告态** | 战斗开局，及之后**每轮 RoundStart**——在任何单位（含我方第一个行动者）行动**之前** | 本轮敌人意图已结算：凡"将攻击或对己方上 debuff"的敌人，在其目标的**己方头像**上点亮**红色锁定环**并播放脉冲确认动画（内缩回弹+副本放大淡出）；多敌同时预告则依行动顺序逐个点亮（错峰 ~0.1s）。输入封锁、整段 ~0.6s 内完成后进入首个行动者。**目的**：玩家据此在自己回合选择防御/闪避姿态（《战斗系统文档》§3）。轮到该敌人实际行动时不再重播锁定演出 |
| **指令选择态（常态）** | 轮到我方某角色 | 命令栏激活、焦点默认"行动"；中央框上 1/3 显示"**✦ [姓名]的回合。**"；演出框切换为该角色动画；弧线顺序条滚动一格、中央头像球放大描金；该角色状态卡亮橙缘 |
| **异常跳过回合态** | 轮到某角色但其带"跳过行动"类异常（MVP：眩晕；扩展：睡眠/疯狂等） | 顺序条照常滚动一格、该角色头像球到位描金，状态卡亮橙缘；但命令栏**不激活**、不进入指令选择；中央框显示"**✦ [姓名]因[状态]无法行动。**"；输入封锁、短暂停留（~1s）后自动结束该角色回合推进下一行动者；眩晕按"短（1 回合）"在本次跳过后解除（《战斗系统文档》§2），状态卡对应 chip 移除 |
| **二级选项态** | 命令栏选中"行动/技能/物品"按 `Z` | 中央框下 2/3 两列选项展开（**行动子项 = 攻击 / 防御 / 闪避**；技能列表；物品列表），上 1/3 原文字不变；焦点落首个可用项；`X` 收起返回命令栏 |
| **姿态保持态** | 行动子项选"防御"或"闪避"按 `Z` | **无目标选择**，立即生效并结束该角色回合；该角色状态卡姓名旁出现姿态小图标（盾形=防御 / 残影形=闪避，骨白 8×8）；姿态保持至**该角色的下一个行动回合**开始时自动清除；受击结算按姿态执行（防御减伤——不完美格挡的 MP 消耗随诅咒等级稍增；闪避位移——距离随诅咒等级稍减） |
| **选项置灰变体** | MP 不足的技能 / 缓解物 / 数量为 0 后的物品 | 对应条目置灰但保留位置；焦点跳过置灰项 |
| **选项翻页变体** | 可选项 > 6（2 列×3 行） | 显示翻页指示 ▼；焦点移动到页尾继续下移时自动翻页 |
| **目标选择态** | "攻击"或需要目标的技能/物品确认后（**防御/闪避不进入此态**） | 敌方目标（仅攻击与攻击型技能/物品）：当前目标立绘正常亮度+金色准星（旋转+淡入），其余敌人压暗；中央框显示"▶ [目标名]"；我方目标（治疗/物品）：焦点在状态卡间移动、当前卡高亮；`X` 返回上一步 |
| **准星确认演出** | 目标上按 `Z` 确认攻击/技能 | 金色准星小幅内缩→迅速回弹原尺寸→同位置生成放大+渐透明至 0 的准星副本后销毁（"锁死目标"脉冲）；随后进入转盘/执行 |
| **力度转盘态** | 攻击指令确定目标后 | 转盘居中于中央框、底板不透明；命令栏弱化不可交互；**失误档占比按当前角色诅咒等级缩放：平稳 20% / 躁动 40% / 侵蚀 70% / 濒临 85%**，其余档（完美/良好/普通）在剩余占比内按原比例缩放；`Z` 定格 → 显示档名/倍率 → 短暂停留后关闭 |
| **行动执行演出** | 指令全部确认完毕 | 演出框播放攻击/施法动画；命中时敌方立绘受击闪烁、伤害数字弹出；我方 HP/MP 条与数字即时刷新 |
| **敌方回合扩张态** | 轮到敌人攻击己方 | 锁定演出已在本轮 RoundStart 的锁敌预告态完成、**此处不再重播** → 直接中央框+演出框扩张（向上至 y≈28、中央框向左至 x≈6 覆盖状态列）、命令栏消失 → 演出框播敌人攻击动画、中央框播我方受击演出（**无文字**）→ 结算后回落复位 |
| **敌方上 debuff 演出** | 敌人对己方角色施放 debuff | 走扩张态同款流程（锁定已在预告态完成，此处直接扩张）；演出框播敌人施法动画，中央框播目标角色被**诅咒紫雾缠绕**的演出（无文字）；回落后目标状态卡闪紫一次，姓名旁出现 debuff 小图标（8×8 诅咒紫底；MVP 最小集：眩晕/中毒） |
| **敌方互 buff 演出** | 敌人对敌方单位（含自身）施放 buff | **不扩张**：施法敌人立绘短暂亮起+施法粒子；目标敌人立绘被**血红色上升粒子**环绕（~0.8s）；中央框单条文字播报（如"✦ 猎手的气息变得凶戾。"）；演出结束后在该敌人**立绘下方的 `EnemyStatusRow`** 增加对应 buff chip（每行 ≤6，溢出换行），常驻至该 buff 失效 |
| **敌方被上 debuff** | 我方对敌人施放 debuff / 命中带 debuff 的攻击 | 命中演出后在该敌人 `EnemyStatusRow` 增加对应 debuff chip（诅咒紫底，每行 ≤6 溢出换行）；层数变化时 chip 右下角数字刷新；debuff 失效时 chip 移除、后续 chip 回填空位 |
| **逃跑判定** | 命令栏"逃跑"按 `Z`（无需目标） | 成功：中央框"✦ 成功逃离了战斗。"→ 转场返回野外；失败：中央框"✦ 没能逃掉——[姓名]的回合结束了。"，回合被消耗 |
| **诅咒侵蚀头像框变体** | 我方角色诅咒值 ≥ 躁动 | 该角色状态卡头像框替换为对应等级紫色缠绕变体（躁动=角部藤蔓 / 侵蚀=半圈 / 濒临=整圈+微光）；平稳=普通框 |
| **倒地态** | 我方角色 HP 降至 0 | 状态卡**保留**：整卡去饱和+约 50% 压暗、头像灰化、HP 数字 0 显示血红；该角色退出行动顺序（弧线条上其头像球缩小淡出移除）、**无法行动**；敌我双方的目标选择均**无法选中**该角色；我方未全灭则战斗继续 |
| **队伍人数变体（1~4）** | 入场队伍配置 | 状态卡 1~4 张（统一 26px 卡式贴底向上）；顺序条头像球数随之变化 |
| **敌人数量变体（1~5）** | 入场敌方配置 | 敌方区立绘居中自适应分布；5 体时允许轻微重叠站位 |
| **胜利结算** | 敌方全灭（ActionResolve 判定） | 中央框显示"✦ 战斗胜利！"+ 掉落物文字清单（如"获得了 灰烬药膏 x1"，不开战利品弹层）；任意确认键后转场返回野外；**被击败的明雷敌人实例从野外地图移除**（当前实现存在不移除的 bug，修复任务见 Open Questions/实现侧） |
| **失败结算** | 我方全灭 | 中央框显示失败文字 + **丧失 50% 金钱与主角当前升级经验进度**的结算文字；**停留 3 秒**（让玩家读完损失信息）后转场返回**上一个存档点**（HP/MP 重置、诅咒值保留）；停留期间按 **`Z` 可跳过停留动画**立即转场；死亡位置生成"遗落光点"实例（见下方扩展设计） |

> 已确认裁剪：诅咒"濒临"阶段的"失神跳过回合"表现**暂不做**（新版诅咒机制中跳过回合本身已被移除，见《通用文档》§4.3 修订版）。

### 失败结算扩展：死亡遗落（Death Cache）

> 此实例存在于**野外探索场景**，不在战斗画面内，但作为失败结算流程的组成部分在此规格化。特效设计参考 godot-prompter:particles-vfx skill。

**机制流**：
1. 战斗失败 → `GameData` 记录 `{lost_gold, lost_exp_progress, scene, position}`（position = 触发战斗的死亡位置）→ 玩家返回上一个存档点。
2. 对应野外场景 `_ready` 时检测到遗落记录 → 在记录位置实例化 `DeathCache`。
3. 主角靠近（**圆形距离判定**：`global_position.distance_to(player.global_position) < 16px`，物理帧轮询或 Area2D 圆形 CollisionShape）→ 触发回收 → 返还全部遗落金钱与经验进度 → 实例销毁、记录清空。

**视觉规格（常驻态）**——白色发光、悬空、边缘模糊的光点：
- `GPUParticles2D` 连续发射：`amount≈12`、`lifetime≈1.6s`、`one_shot=false`、`preprocess≈2.0`（防止入场时粒子突然出现）、`emission_shape=SPHERE` 半径 3px、初速 2~4px/s 朝上（`direction=(0,-1,0)`、`spread=180°`）、`gravity=(0,0,0)`（悬空不坠落）、`scale_curve` 1.0→0.0、`color_ramp` 纯白 α0.9 → α0；务必设置 `visibility_rect`。
- 贴图：8×8 软边圆（高斯衰减）——该光点是"非物质灵光"，**允许例外地打破硬边像素规则**以表达"边缘模糊"；若坚持像素一致性可用 dithering 软圆替代。
- 悬浮感：粒子节点本体用 Tween 做 ±2px、周期 ~2s 的正弦上下浮动。
- 微光：叠一盏低能量 `PointLight2D`（白色、energy≈0.4、半径≈24px）。

**回收动画（玩家靠近触发）**：
- 常驻粒子 `emitting=false`（存量自然消亡）。
- "飞向主角"：生成 8~12 个独立小 `Sprite2D`（4×4 白点）+ 各自 Tween（随机延迟 0~0.15s、时长 0.3~0.5s、`TRANS_EXPO`/`EASE_IN`）直线飞向玩家**实时位置**后逐个销毁——独立 Sprite+Tween 方案比纯粒子方案能精确命中移动中的玩家，数量小、成本可忽略。
- 全部到达后：主角 modulate 闪白一次（0.1s），返还金钱与经验进度，`DeathCache.queue_free()`。

**依赖缺口**：金钱、经验/等级、存档点三个系统目前均未实现（Demo 阶段无此三者），死亡遗落依赖其先行落地——记入 Open Questions。

## Interaction Map

**输入方式**：纯键盘——方向键/WASD（导航）+ `Z`（确认）+ `X`（取消/返回），与全项目键位约定一致（《通用文档》§1.2"键盘即手柄"）；无鼠标、无手柄、无触屏。战斗中 `Tab`（背包热键）失效。

| 状态 / 组件 | 操作 | 输入 | 即时反馈 | 结果 |
|---|---|---|---|---|
| 锁敌预告态（每轮开局） | （无操作） | 输入封锁 | 被锁己方头像点亮红色锁定环+脉冲动画，预告本轮哪个敌人将打谁；~0.6s | 自动进入本轮首个行动者 |
| 异常跳过回合态 | （无操作） | 输入封锁 | 命令栏不激活；中央框显示"✦ [姓名]因[状态]无法行动。"；停留 ~1s | 自动结束该角色回合，推进下一行动者 |
| 命令栏 | 切换命令 | `←`/`→`（A/D） | 金色指针+描边移到新格；置灰格被焦点跳过 | 仅 UI 状态 |
| 命令栏 | 确认命令 | `Z` | "行动/技能/物品"：中央框下 2/3 两列选项展开；"逃跑"：直接进入逃跑判定 | 进入二级选项态 / 逃跑结算 |
| 二级选项（两列网格） | 移动焦点 | `↑↓←→`（WASD） | 金色描边+指针在网格内四向移动；置灰项跳过；焦点在页尾继续下移时自动翻页（▼ 指示刷新） | 仅 UI 状态 |
| 二级选项·攻击 | 确认 | `Z` | 进入目标选择：首个合法敌人立绘亮起+金色准星旋转淡入，其余压暗 | 进入目标选择态 |
| 二级选项·防御/闪避 | 确认 | `Z` | **无目标选择**：状态卡姓名旁姿态小图标出现（盾/残影）；中央框文字播报（如"✦ [姓名]摆出了防御的架势。"） | 写入该角色 `pending_stance`；回合立即结束，顺序条滚动 |
| 二级选项·技能/物品 | 确认 | `Z` | 攻击型→敌方目标选择；治疗/增益型→我方目标选择（状态卡间焦点） | 进入目标选择态 |
| 二级选项 | 收起返回 | `X` | 选项网格收起，焦点回到命令栏原命令格 | 返回指令选择态 |
| 目标选择（敌方） | 切换目标 | `←`/`→` | 金色准星旋转+淡入移到新目标立绘上方；新目标恢复亮度、旧目标压暗；中央框"▶ [目标名]"刷新 | 仅 UI 状态 |
| 目标选择（我方） | 切换目标 | `↑`/`↓` | 焦点在状态卡间移动、当前卡高亮（倒地角色跳过） | 仅 UI 状态 |
| 目标选择 | 确认目标 | `Z` | **准星确认脉冲动画**（内缩回弹+副本放大淡出）；攻击→转盘升起；技能/物品→直接进入执行演出 | 锁定目标；进入转盘态 / 执行 |
| 目标选择 | 取消 | `X` | 准星淡出，敌方立绘恢复，回到二级选项网格（焦点保留原项） | 返回二级选项态 |
| 力度转盘 | 定格 | `Z` | 指针定格，显示档名/倍率，短暂停留后转盘关闭 | 倍率写入攻击者；进入执行演出（**无 `X` 取消**——起转即不可反悔） |
| 执行/结算演出 | （无操作） | 输入封锁 | `Z`/`X` 均不响应（《战斗系统文档》§B.3：结算阶段不可取消） | 演出完毕自动推进 |
| 敌方回合扩张态 | （无操作，MVP） | 输入封锁 | 同上；**预留**：未来弹幕演出在此态接管 WASD（移动判定点）+ `Shift`（冲刺）+ `Z`（弹反） | 演出完毕回落，推进下一行动者 |
| 胜利结算 | 确认离开 | `Z` | 转场开始 | 返回野外（敌人实例已移除） |
| 失败结算 | 跳过停留 | `Z` | 立即结束 3 秒停留、开始转场（`X` 不响应） | 返回上一个存档点，死亡处生成遗落光点 |

**焦点规则补充**：
- 任何时刻屏幕上**有且仅有一个**金色焦点（命令格 / 选项格 / 目标准星 / 我方目标卡），避免双焦点歧义。
- 二级选项打开时默认焦点 = 首个**可用**项（跳过置灰）；从目标选择 `X` 退回时恢复退出前的焦点项。
- 倒地角色（HP=0）在我方目标选择中被跳过（不可选中）。

## Events Fired

本项目无分析系统，事件 = 游戏内信号（供 BattleManager / GameData / 演出层解耦用）。

| 玩家操作 | 触发事件 | Payload / 数据 |
|---|---|---|
| 切换命令 / 焦点移动 / 翻页 / 收起菜单 | 无事件（纯 UI 状态） | — |
| 选定姿态（防御/闪避） | `stance_selected` | `actor_id`, `stance`——写战斗副本内的 `pending_stance`，不持久化 |
| 转盘定格 | `wheel_resolved`（**已有信号**，AttackPowerWheel） | `multiplier`, `tier_name` |
| 攻击/技能执行完毕 | `action_executed` | `actor_id`, `action_type`, `target_id`, 结果数值（伤害/治疗量）——演出层与镜头（BattleStage）订阅此事件 |
| 战斗内使用物品 | `item_used`（**GameData 已有**） | `item_id`——⚠️ 写背包（战斗副本，胜利才写回） |
| 逃跑 | `escape_attempted` | `success: bool` |
| （每轮开局自动）锁敌预告 | `enemy_intent_telegraphed` | `[{enemy_id, target_id, intent: attack\|debuff}]`——准星/锁定层订阅以点亮红环；要求本轮敌方意图在 RoundStart 预先结算 |
| 我方角色倒地 | `unit_downed` | `unit_id`——顺序条移除头像球、状态卡切倒地态均订阅此事件 |
| 战斗结束 | `battle_ended`（**已有**，Battle.gd） | `victory`——⚠️ 胜利：写回 HP/MP/物品 + `mark_enemy_defeated`；失败：触发死亡惩罚链 |
| （失败自动）死亡惩罚 | `death_penalty_applied` | `lost_gold`, `lost_exp_progress`, `scene`, `position`——⚠️ 写 GameData 持久化遗落记录 |
| （野外）遗落回收 | `death_cache_recovered` | `gold`, `exp_progress`——⚠️ 写回 GameData，清空遗落记录 |

⚠️ **架构关注点**：
1. 所有持久化写入仍走"BattleManager 战斗副本 + 胜利单点写回"的既有契约（《通用文档》§B.2），事件只做通知不直接改数据。
2. `death_penalty_applied` / `death_cache_recovered` 依赖金钱、经验、存档点三个未实现系统，事件名先约定、字段后补。
3. 演出与镜头一律经 BattleStage 订阅事件触发，不在战斗逻辑里直接调镜头。
4. **锁敌预告要求敌方意图前置结算**：红环预告发生在每轮 RoundStart、所有单位行动前，因此敌人的攻击/上 debuff 目标必须在 RoundStart 阶段就由 AI 预先决定并冻结（不能等到敌人各自回合才即时决策）。这与《战斗系统文档》B.1 "敌人回合即时生成指令+目标"是一处需要协调的改动——见 Open Questions / 战斗文档 §3 同步。

## Transitions & Animations

| 动画 | 触发 | 规格 |
|---|---|---|
| **战斗入场转场** | 野外触碰敌人 | SceneManager 既有 0.3s ColorRect 淡入淡出遮罩；进战斗后各 UI 分层**自下而上依次淡入**（背景→敌方立绘→我方状态列→中央框→命令栏，错峰约 0.05s/层），约 0.4s 完成 |
| **弧线顺序条滚动** | 回合变更 | 所有头像球沿弧线从右往左滑一格（~0.25s，`TRANS_CUBIC`/`EASE_IN_OUT`）；左端球缩小+淡出销毁、右端新球放大+淡入；中央球到位后描金闪一下 |
| **准星入场** | 进入目标选择/切换目标 | 金色准星旋转一圈（~0.2s）+ 淡入；切换目标时从旧位置滑到新位置 |
| **准星确认脉冲** | 确认目标 `Z` | 准星小幅内缩（~0.08s）→ 回弹原尺寸（~0.08s）→ 同位生成副本放大至 1.5×+ α 渐 0（~0.25s）后销毁 |
| **锁敌预告（红环）** | 战斗开局 / 每轮 RoundStart，所有行动前 | 将攻击/上 debuff 的敌人，在其目标己方头像上点亮红色锁定环 + 同套脉冲确认动画；多敌按行动顺序错峰 ~0.1s 逐个点亮；整段 ~0.6s，输入封锁 |
| **力度转盘升起/收起** | 攻击确认目标后 / 定格 | 升起：转盘从中央框中心缩放淡入（~0.2s）；定格后停留 ~0.5s 显示档名再缩放淡出 |
| **敌方回合扩张/回落** | 敌方行动开始/结束 | 中央框+演出框用 Tween 同步扩张（向上至 y≈28、向左至 x≈6，~0.3s `TRANS_QUAD`）；命令栏淡出；演出毕反向回落 ~0.3s；**由 BattleStage 与镜头运动同步触发** |
| **受击闪烁** | 命中敌方/我方 | 立绘 modulate 红白闪 2~3 次（~0.3s 总长） |
| **伤害数字** | 命中结算 | 数字从目标上方弹出+上浮+淡出（~0.6s） |
| **倒地态过渡** | HP 归 0 | 状态卡去饱和+压暗（~0.4s 渐变）；顺序条对应头像球缩小淡出 |
| **失败结算停留** | 我方全灭 | 中央框失败/损失文字停留 **3s** 后自动转场；停留期间按 `Z` 立即跳过余下停留并起转场 |
| **死亡遗落浮动** | 常驻 | 光点节点 ±2px 正弦上下浮动（周期 ~2s）；粒子层持续 |
| **遗落回收** | 玩家靠近 | 小白点逐个飞向玩家实时位置（0.3~0.5s，`TRANS_EXPO`/`EASE_IN`）；全部到达后主角闪白一次（0.1s） |

> 诅咒侵蚀头像框的形态切换（平稳/躁动/侵蚀/濒临四态，对应不同紫色缠绕程度的 `avatar_frame_curse_*` sprite）属于**静态状态展示**，已在 Layout Specification 与 States & Variants 中规定；本节不再单独定义切换动画。

**镜头编排说明**：所有镜头运动（shake / zoom / pan）由 BattleStage 经 phantom-camera 虚拟机位 priority 切换驱动，与上述 UI Tween **同一时序触发**；本节只定义 UI 层动画，镜头语言（哪个动作配哪种 shake/zoom）留待后续演出设计。

## Data Requirements

战斗画面是**重读取、轻写入**：开战时从 GameData 拉一份战斗副本，全程只读副本驱动 UI，**仅在战斗结束时单点写回**（《通用文档》§B.2 战斗数据隔离契约）。

### 读取（进入战斗时）

| 数据 | 来源 | UI 用途 |
|---|---|---|
| 队伍成员 1~4 人 | `GameData.party_members[]`（`id`/`display_name`/`hp`/`mp`/`max_hp`/`max_mp`/`atk`/`def`/`spd`/`status_effects`） | 我方状态列每张卡：姓名、HP/MP 条、头像、异常 chip |
| 各成员诅咒等级 | `GameData.get_curse(id)`（0~100，分 4 档映射 0~3） | 头像框形态选择（`avatar_frame_curse_*`）+ 攻击转盘失误占比 |
| 各成员羁绊值 | `GameData.get_bond(id)`（0~10，MVP 预留） | **暂不在战斗 UI 展示**（已决定本期不加入） |
| 敌人配置 | `Battle.ENEMY_RESOURCE_PATHS[enemy_key]` → `EnemyStats.tres`（立绘、`max_hp`/`atk` 等） | 敌方区立绘（1~5 体居中，无名无血条） |
| 背包 | `GameData.inventory[]`（`{item: ItemData, count}`） | 「物品」二级列表（仅名称，无图标） |
| 物品定义 | `ItemData`（`id`/`display_name`/效果） | 列表条目文本、使用效果结算 |

### 战斗副本（仅存活于 Battle.gd 生命周期，不持久化）

| 数据 | 持有方 | 说明 |
|---|---|---|
| `BattleUnit` 实时 HP/MP/状态 | `Battle._party_units` / `_enemy_units` | 由 `BattleUnit.from_party_member()` 从 GameData 拷贝，伤害/治疗只改副本 |
| 行动顺序 | `Battle._turn_order` / `_turn_index`（由 `spd` 计算） | 弧线顺序条头像球排布 |
| `pending_stance` | 战斗副本内（每角色一项） | 防御/闪避姿态，持续到该角色下次行动；**不写 GameData** |
| 背包快照 | `Battle._inventory_snapshot = GameData.duplicate_inventory()` | 失败时 `restore_inventory()` 回滚物品消耗 |
| 转盘结果 | `AttackPowerWheel.wheel_resolved` 临时值 | 仅用于本次伤害结算，不留存 |

### 写入（战斗结束，单点）

| 时机 | 写入 | 现状 |
|---|---|---|
| 胜利 | `_sync_party_to_gamedata()` 回写 HP/MP/`status_effects`；`mark_enemy_defeated(enemy_key)` 记录野外敌人已击败 | 回写已实现；`mark_enemy_defeated` 在 `feat/inventory-ui`(dc90fc6) 已落地 |
| 失败 | `_reset_party_hp_mp()` 重置 HP/MP + `restore_inventory(snapshot)` 回滚物品 | 已实现 |
| 失败（设计目标） | 扣 50% 金钱 + 经验进度 + 写持久化死亡遗落记录（场景/坐标/数额） | ⚠️ **依赖金钱、经验、存档点三个未实现系统**——`death_penalty_applied` 字段先约定、后补，记 Open Questions |
| 遗落回收 | 回写金钱/经验、清空该条遗落记录 | ⚠️ 同上，依赖未实现系统 |

### 缺口标记

1. **金钱 / 经验 / 存档点系统尚不存在**——失败结算与死亡遗落的数据写入只能先占字段（转入 Open Questions 的 TODO）。
2. **多敌阵容数据已打底**：`Battle.gd` 现支持以 `enemy_keys` 列表（回退单 `enemy_key`）构建 1~N 体敌方单位，战斗主循环与 `BattleUI` 数组驱动渲染，**不绑死敌人数量**。遗留：敌方立绘的多体居中坐标/缩放属 UI 视觉层细节，待实现多敌画面时补。
