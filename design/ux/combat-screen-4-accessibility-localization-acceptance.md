## Accessibility

本项目无手柄/触屏，**全键盘操作**即基础可达性底座；以下为战斗画面专项考量。

### 输入与操作

| 项 | 规格 |
|---|---|
| 全键盘闭环 | 方向键/WASD 导航、`Z` 确认、`X` 取消，无需鼠标；所有可交互项均可由键盘抵达（见 Interaction Map） |
| 单焦点规则 | 任一时刻只有一个高亮焦点，焦点框为金色描边，移动有 0.25s 内的即时反馈，避免「焦点丢失」 |
| 无时间压力 | 回合制，指令选择/目标选择**不计时**；唯一的实时元素是攻击力度转盘，且其节奏为设计核心 |
| 演出期输入封锁 | 演出/镜头运动期间封锁输入并有明确视觉提示（命令栏淡出），避免误操作 |

### 视觉与可读性

| 项 | 规格 |
|---|---|
| 不依赖单一颜色编码 | HP/MP 用**颜色 + 数值文本**双重表达；异常状态**不依赖文字**，用 **chip 图标**表示种类、图标右下角的**数字**表示层数；诅咒等级用**头像框形态差异**（藤蔓覆盖程度）而非仅紫色深浅 |
| 敌方无血条的代偿 | 敌方刻意不显 HP/名称（设计基调），但受击有红白闪 + 伤害数字反馈，确保「打中了/打了多少」可感知。**TODO：后续为敌方加入专门的受击动画**，进一步强化命中反馈 |
| 敌方状态可读 | 敌人的增益/异常以 chip 行紧贴立绘下方常驻显示（每行 ≤6、溢出换行、右下角数字表层数），与我方 `StatusIconRow` 同一套图标+层数编码，不依赖文字也不依赖单一颜色——玩家可随时核对"这只敌人现在被强化/弱化了什么" |
| 文本对比度 | 战况文字用骨白 `COL_BONE` 压深色框底；最小字号遵循像素字体 1:1 不缩放，保证 480×270 基准下可读（×4 输出） |
| 像素硬边例外 | 死亡遗落软边圆贴图是规则唯一例外，已在 States & Variants 标注，不影响整体清晰度 |

## Localization Considerations

战斗画面文本量小但高频，且像素字体对字宽/字形敏感，本地化需重点关注**文本扩展**与**字体覆盖**。

### 文本资产清单

| 类别 | 示例 | 来源 |
|---|---|---|
| 命令项 | 攻击 / 防御 / 闪避 / 物品 / 逃跑 | UI 静态文案 |
| 战况文字 | 「✦ [姓名]的回合。」「✦ 遭遇了 猎手！」「✦ 造成 12 点伤害」 | 模板字符串 + 运行时插值 |
| 姓名 | 角色 `display_name`、敌人名 | `CharacterStats` / `EnemyStats` 资源 |
| 物品名 | 二级物品列表条目 | `ItemData.display_name` |
| 转盘档名 | 暴击 / 强力 / 普通 / 失手 等 | `wheel_resolved.tier_name` |
| 结算横幅 | 胜利 / 战败 | UI 静态文案 |

### 字符上限（QA / 翻译核对用）

> 中文基准为版式设计值；"英文允许值"为不破版的硬上限，超出须缩字号或截断（命令项）/省略号（姓名）。480×270 基准、像素字体 1:1。

| 文本元素 | 中文基准 | 英文允许值（硬上限） | 超限处理 |
|---|---|---|---|
| 命令栏标签（行动/技能/物品/逃跑） | 2 字 | 8 字符 | 自动缩字号→截断 |
| 行动子项（攻击/防御/闪避） | 2 字 | 8 字符 | 自动缩字号→截断 |
| 角色 `display_name`（状态卡 / 顺序条） | 3 字 | 10 字符 | 省略号兜底 |
| 敌人名（中央框"▶ [目标名]"） | 4 字 | 14 字符 | 省略号兜底 |
| 中央框战况文字（单行，最多 3 行） | 14 字/行 | 40 字符/行 | 自动换行（最多 3 行内） |
| 技能/物品选项条目（单列宽） | 6 字 | 16 字符 | 截断+省略号 |
| 转盘档名（完美/良好/普通/失误） | 2 字 | 8 字符 | 缩字号 |
| 结算横幅（胜利/战败） | 4 字 | 16 字符 | 缩字号 |

### 关注点

| 项 | 规格 |
|---|---|
| **文本扩展** | 命令栏槽位与状态卡宽度按中文设计（2~3 字）；英文/德文可能 2~3 倍长。命令项应支持**自动缩字号或截断**，状态卡姓名预留省略号兜底（上限见上表） |
| **模板插值语序** | 战况文字含 `[姓名]`、数值插值——禁止用字符串拼接，须用带占位符的格式串（如 `"✦ %s 造成 %d 点伤害"`），让译文可调整语序 |
| **字体覆盖** | 当前像素字体的字符集需覆盖目标语言；CJK 像素字体字形大、占位多，与拉丁字母混排时**行高/基线**需统一校验 |
| **数字与标点** | HP/MP 数值、伤害数字为阿拉伯数字全语言通用；但全角/半角标点（如「✦」「！」）在不同语言下的呈现需检查 |
| **不翻译项** | 七色色板语义名（`COL_*`）、事件名、资源 id 等为代码标识，**不进翻译表** |

### 现状与缺口

- 项目**尚无本地化系统**（无 `TranslationServer` 接入、无 `.po`/`.csv` 字符串表）。当前文案为中文硬编码。
- 本节为**前向约定**：要求新写的战斗 UI 文案一律走可替换的字符串常量 + 格式串，避免日后回填本地化时大改；正式 i18n 架构记 Open Questions。

## Acceptance Criteria

实现后须逐项满足；勾验方式以「文本门」（run_project 无错）+「像素门」（capture.gd 截图比对）为主。

### 布局与分层

- [ ] 七分层 HUD 全部就位：弧线顺序条、敌方区、中央框、演出框、命令栏、我方状态列、准星/锁定层
- [ ] 我方 1~4 人状态卡统一 26px、卡顶不超过中央框上沿、随人数居中排布
- [ ] 敌方 1~5 体纯立绘居中，**无名称、无 HP 条、无低血量暗示**
- [ ] 中央框文字靠左上 1/3，二级选项两列布局在下 2/3、无标题行
- [ ] 上半屏不再是纯黑空白——森林背景生效，呈「局部发光 + 氛围感」基调

### 交互（全键盘）

- [ ] 方向键/WASD 导航、`Z` 确认、`X` 取消形成闭环，无需鼠标
- [ ] 任一时刻仅一个金色焦点；倒地角色被自动跳过
- [ ] 防御/闪避选定后**无目标选择**、立即结束回合，姿态保持到该角色下次行动
- [ ] 攻击力度转盘定格后**不可反悔**；演出/镜头运动期间输入被封锁
- [ ] 带"跳过行动"异常（眩晕）的角色轮到时不进指令选择、中央框播报无法行动、自动推进
- [ ] 失败结算停留 3 秒后自动转场，且停留期间按 `Z` 可立即跳过

### 视觉与状态

- [ ] 诅咒等级 0~3 对应四种头像框形态（藤蔓覆盖程度递增），非仅紫色深浅
- [ ] 异常状态用 chip 图标 + 右下角数字层数表示，**不依赖文字**
- [ ] HP/MP 同时有颜色与数值文本
- [ ] 准星出现/切换播放旋转+淡入；确认目标播放脉冲动画
- [ ] 每轮开局、所有单位行动前播放**锁敌预告**：将攻击/上 debuff 的敌人在其目标己方头像点亮红环
- [ ] 敌方异常/增益以 chip **紧贴立绘下方成行**显示，单行 ≤6、溢出换行，右下角数字表层数
- [ ] 敌方回合扩张态向上+向左覆盖状态列，演出毕回落；命令栏在演出期淡出
- [ ] 倒地态状态卡去饱和+压暗且**不消失**；顺序条对应头像球淡出

### 数据与流程

- [ ] 战斗全程只读战斗副本；HP/MP/物品消耗仅在结束时单点写回
- [ ] 胜利回写 HP/MP/状态并 `mark_enemy_defeated`，该野外敌人下次进图不再出现
- [ ] 失败重置 HP/MP 并回滚物品快照
- [ ] 所有演出/镜头经 BattleStage 接口触发，战斗逻辑不直接调镜头

### 性能

- [ ] 战斗入场转场（各 UI 分层自下而上错峰淡入）在 **~0.4s 内**完成，过程不掉帧
- [ ] 锁敌预告、敌方回合扩张/回落等 Tween 演出保持 60fps，无可见卡顿
- [ ] 5 敌 + 4 人满阵容时，转盘旋转与受击演出帧率不低于常规阵容

### 退化与边界

- [ ] 失败结算的金钱/经验/遗落写入在依赖系统就绪前以占位字段存在，不阻塞战斗主流程
- [ ] 敌方阵容支持 1~N 体：进场以 `enemy_keys` 列表或单 `enemy_key` 传入，战斗主循环与 UI 不绑死敌人数量

| 失败结算停留（/ux-review Issue 6） | 停留 **3s** 让玩家读完损失信息，期间 `Z` 可跳过 |
| 交互模式库（/ux-review Issue 7） | 已创建 `design/ux/interaction-patterns.md`，登记本 spec 全部新模式 |
