# 用单一世界圣经和逐地审阅治理正典

世界观从零散 Spec 迁入根目录 `world-bible/`，以作者源快照、显式正典状态和普通相对链接维护唯一事实源；A–P 每地独立提出、提交和审阅，获批后才能成为后续设定的依据。这取代了先写孤立试稿、再把未审内容当成共同前提的方式，也避免在桌面 `map.txt` 与仓库文档之间双写。

本决定保留 ADR-0001 的生态—租权—政体因果链，但取消“每个聚落体默认需要地方标志种或生计支柱种”的隐含要求。生物先属于跨境生态系统，只有确实改变生产、权力、建筑、生活或剧情时才进入聚落档案。旧 A/E/O/P 试写整体废止，不从中继承物种、政体、人物、危机或六区划分。

## Consequences

- 原始地图与笔记只读；修订发生在有状态、有来源的世界条目中。
- `Established`、`Proposed`、`Speculative`、`Deprecated` 与 `Contradicted` 明确区分，作者是唯一正典裁定者。
- 作者真相与玩家表象分层；世界不因当前 Demo 的主角、森林或玩法占位而倒推。
- 超自然已确认同源、解释分裂、机构只能概率复现、个人奇迹不可复现；成本和作用尺度解决前不得成为国家能力支柱。
