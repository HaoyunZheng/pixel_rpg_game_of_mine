# 以生态—租权—政体因果链构建聚落

A–P 后续设定采用完整原创生物圈，并从“生态约束 → 可排他资产 → 租权集团 → 统治联盟 → 社会冲突 → 文化后果 → 精神追问”推演每个聚落体；社会现状必须由早期生计秩序、排他资产与租权形成、当代统治联盟与危机三阶段解释。每地物种分为形成地方辨识度与事件条件的地方标志种，以及足以重组生计、阶级或外交的生计支柱种，并始终使用先说明作用、再承载文化含义的功能性名称。此决定放弃用文明标签拼贴社会、用装饰性怪兽制造差异，或把现实国家一对一换皮，因为这些做法不能解释租权来源、社会演进与可执行的剧情冲突。

## Consequences

- 生态功能区可以跨越聚落边界，政治疆域不再被当作生态边界。
- 原创物种必须先证明身体结构、能量取得、气体交换、运动、繁殖、生态位、选择优势、生存代价与分布边界，再承担文化或剧情功能。
- 社会推演以成熟铁器、畜力、帆船、河运和水力的中世纪物质技术为常态；局部制度复杂度不等于火药、工业能源或大众印刷普及。
- 七维能力模型继续描述聚落体的能力结构，但旧评分矩阵暂停使用，待 A–P 完成新因果模型后统一重算。
