## 0. 试写契约

### 0.1 推演方法

每个社会沿同一条可追溯链展开：

> 生态约束 → 可排他资产 → 租权集团 → 统治联盟 → 社会冲突 → 文化后果 → 精神追问

“地图事实”沿用地理 Spec 的 F／I／O 证据口径。生物、制度与人物是本轮设计提案，不冒充地图事实；任何一项若依赖未制图的湖泊淡咸、港口位置或河流方向，均明确保留不确定性。

### 0.2 时代、生物与命名边界

- 物质技术以成熟铁器、畜力、帆船、河运与水力为上限常态；没有普及火药、工业能源、大众印刷或现代实验科学。
- 四地物种全部按自然生物物理解释。本稿不赋予低度超自然生理，也不以超自然弥补粮食、燃料、道路或组织缺口。
- 生物名称都是“先说功能、后留文化含义”的工作称号，不创建虚构谱系、永久语言词根或分类学拉丁名。
- 居民可以凭长期经验识别腐斑、歉收与接触后的连锁衰败，但不知道微生物病原学；本稿不预设现代检疫、国家公共卫生或无成本的科学育种。
- 现实历史参照推迟到 A–P 全部完成后再写。本稿不把任何真实国家、民族性格或制度整包换皮。

### 0.3 物种层级

- **地方标志种**回答“来到这里会看见什么独特生活痕迹”，可以影响节令、服饰、禁忌或剧情识别，但未必支撑宏观剩余。
- **生计支柱种**回答“它若衰退，哪些产权、职业、财政和外交会一起改变”。一项物种可以同时处在两个层级，但正文必须分别说明其辨识作用与结构作用。
- 生计支柱种不能是无代价的万能资源。它必须具有生长速度、分布边界、繁殖瓶颈、天敌或环境脆弱点，使垄断和危机有物质基础。

## 1. 六个生态功能区

六区共同构成本世界原创生物圈的功能骨架，按能量流、水热节律和跨境迁徙划分，不按 A–P 的疆域线划分。下列物种名只固定生态功能；后续扩展某地时，仍须另写完整物种卡。

### 1.1 高纬寒海与冻原｜B、D、南寒岛

- **能量来源**：低角度但漫长的夏季日照、寒海上涌带来的溶解养分，以及 B 的局部地热；地热只扩大少数无冰斑和浅水繁殖场，不改变整个高纬区的低生产力。
- **生产者**：贴附黑岩吸热的“暗面膜”、冰缘下垂的“盐帘叶”、融雪洼地中以地下贮藏节熬过长冬的“伏芽毡”。三者分别固定岩岸、海冰边缘与冻原表层。
- **主要取食者**：刮食暗面膜、用宽腹储脂的“冰缘铲腹体”；沿冻河啃食伏芽毡并在冬季结队迁移的“暖囊步兽”；在寒海中过滤盐帘叶孢囊和微小漂食体的“梳喉游体”。
- **分解者**：在短夏迅速软化尸体与枯毡的“热腐囊”，以及在缺氧冻泥中缓慢发酵、释放可被伏芽毡再利用盐类的“灰泥丝”。分解受温度限制，养分常被锁在冻土或海底。
- **环境威胁**：海冰年份突变、春季凌汛、冻土融陷、连续阴夏、火山灰遮光和寒岛强风。高纬生物多能承受一次严寒，却难以承受连续两个繁殖窗口消失。
- **季节循环**：冬季大部分陆生生产停滞；解冻初期先出现河口腐食脉冲，继而是海冰退缩后的过滤旺季；短夏完成交配、贮脂和孢囊沉积，秋季风暴前生物向深水、地热斑或林线南侧收缩。
- **跨境迁徙**：暖囊步兽沿 D 的冻河与无字母雪原往返，梳喉游体随寒流经过 B—C 航线，南寒岛的沿岸取食群会越过 G 宣称的殖民海面。任何聚落体若封闭整条迁徙线，代价都会在别处的食物和分解循环中显现。

### 1.2 西风湿润海岛—森林湖原｜C、E、F、G

- **能量来源**：西风带来稳定水汽，长而温和的生长季支撑森林冠层、林下耐阴层、湖面浮生层和河口盐淡交错带；能量多但大量被锁在木质体和湿土中。
- **生产者**：以中空立柱储水、根盘相互扣合的“冠柱林”；在林隙快速铺开的“雨羽叶”；湖岸与缓流中形成可食地下节的“浅根席”；E 的迁游生物依赖大湖浮生层与小湖繁殖带。
- **主要取食者**：啃食冠柱林嫩梢并替其搬运硬果的“钩背攀兽”；沿河刮取浅根席的“板吻涉体”；春汛在大湖取食、到小湖繁殖的六肢陆水迁游生物。
- **分解者**：钻入倒木、把木质层切成湿纤维的“层齿群”，以及在湖底吞食沉降碎屑、排出黏土状团粒的“沉泥袋”。它们决定森林土壤恢复速度和湖底是否迅速淤平。
- **环境威胁**：连年暴雨导致根盘滑移，风倒阻塞河道，低地洪水把腐殖质冲入湖中造成缺氧；相反，过度清林会让夏季水温上升、河流暴涨暴落。
- **季节循环**：冬末风倒提供分解底物；春汛开启陆水迁游和木材浮运；夏季林冠达到最高生产，大湖取食旺盛；秋季硬果与地下节成熟，迁游生物退离大湖，村社进入修堤和储藏季。
- **跨境迁徙**：硬果搬运兽与河谷取食者跨过 C、F 的人类边界，六肢迁游生物穿越 E 内部的大湖—小湖廊道；沿岸漂生体则在 C、G 与大陆西岸之间流动。森林采伐、堤道和港坝会把生态后果传给下游与邻岸。

### 1.3 中央内海—湿地陆桥｜H、J、K

- **能量来源**：内海浅水日照、河流携带的有机碎屑、季节泛滥带来的矿盐，以及干湿交替形成的高分解脉冲；这里的产量高，却集中在会移动的水陆边界。
- **生产者**：茎内储存淡水、可在盐度变化时封闭下部气孔的“囊节苇”；贴在泥面、旱季卷成硬片的“金褐泥叶”；漂浮于缓流、吸收过量养分的“孔浮盘”。
- **主要取食者**：用分叉足在软泥上分散重量、啃食泥叶的“叉足滩行体”；吞取孔浮盘并把可食囊体带到上游的“网腹游体”；在芦苇根间伏食小型取食者的“折颚伏体”。
- **分解者**：低氧泥中成团发酵的“沼泡菌席”和把芦苇空茎磨成纤维的“管居碎食群”。它们释放的气泡可抬动泥层，也会在封闭仓区形成窒息危险。
- **环境威胁**：河道改道、盐水倒灌、旱季火烧、洪峰叠加以及人工闸堤令一个水体的污染与缺氧集中到另一处。石材和干燥地基稀少，使人类维护成本长期偏高。
- **季节循环**：春季上游来水扩张湿地；盛夏水路最多但虫害和腐败也最强；秋季退水露出泥叶采集面与可步行陆桥；冬季低水位适合修闸、掏淤和重定界桩。
- **跨境迁徙**：叉足滩行体随退水线穿过 H—J—K，网腹游体把营养从内海带入上游水网；人类闸门若为了航运固定水位，会截断这些往返。K 的陆桥不是生态空白，而是湿地群落与较干草地群落重叠的窄带。

### 1.4 东部山前—雪融湖—高原雨影｜A、I、N

- **能量来源**：高山积雪储水、山前冲积泥的矿质更新、强烈而季节集中的日照，以及 I 大湖对温度和水量的缓冲；从 I 向 A、N 雨影区，水而非光逐渐成为首要限制。
- **生产者**：A 河汊中能随洪水抬升的锚定粮垫；I 湖岸以浮根连接林地与浅水的“镜岸冠群”；N 石坡上把短时融水导入地下贮囊的“脊沟垫”。
- **主要取食者**：剪食粮垫边缘、在浅汊间迁步的“束趾涉体”；啃食镜岸冠群落果囊并把种囊带过山口的“厚掌坡行体”；舔食脊沟垫盐析物的“裂蹄高原兽”。
- **分解者**：河泥中分解粮垫残体的“缺氧软结群”、I 林湖交界处处理落体的“浮根碎食带”，以及 N 岩缝内缓慢溶解矿物并利用稀少有机物的“酸尘丝”。
- **环境威胁**：融雪过急造成洪峰和冰湖溃决，雪少年份导致河汊断流；山崩可一夜改道，N 的旱风与盐尘会越过政治边界，A 的低坡则承受旱涝交替。
- **季节循环**：冬季山地蓄雪；春初低地先缺水，随后融雪洪峰重画河汊；夏季 I 湖区保持生产而 A、N 进入水权紧张期；秋季高原取食者下移，河谷集中修索、储粮和清淤。
- **跨境迁徙**：厚掌坡行体可经 I—A/N 山口搬运种囊，裂蹄群在雪线下降时进入 A 的上游牧地；A 河口漂生体又可能随沿岸流抵达东北群岛。关隘封闭和山前筑坝会同时改变人类贸易与非人迁徙。

### 1.5 南方洪泛平原—大海湾｜L、M、O

- **能量来源**：南温带较长日照、山地降水、河流反复输送的细土，以及海湾潮汐把悬浮物推回浅滩；高生产力来自周期性扰动，而不是永不变化的沃土。
- **生产者**：洪泛地上被淤泥掩埋后能从节环再生的“复节高草”；河口耐盐、以根篮截留细土的“潮篮丛”；O 湾内能沉积矿质骨架并固结软泥的造礁群体。
- **主要取食者**：啃食复节高草、随水线迁移的“宽腔群行体”；钻入潮篮丛取食贮根的“楔吻掘体”；O 的大型洄游底栖巨兽会翻动湾泥、破开老化底层并重塑水道。
- **分解者**：洪水后迅速处理倒伏高草的“热堆片群”、潮沟中粉碎根篮残体的“咬砂链”，以及礁孔内过滤碎屑、维持水流的微小管居群。
- **环境威胁**：河道改道、连续歉雨、海湾风暴、盐水上溯、山地采伐造成的突发淤积；若人类把洪水完全排除，土壤与浅湾也会逐年失去更新。
- **季节循环**：春季山雨抬高河水；夏季洪泛草和潮篮丛快速生长；退水期适合收割、播殖礁群和修港；大型底栖巨兽随外海食物与湾内气味在特定潮季进入 O，随后返回深水繁殖区。
- **跨境迁徙**：宽腔群行体沿 M—L 的草水边界移动，河流把两地泥沙与种节带入 O；底栖巨兽越过 O 的领邦界和外海主张线。上游堤坝、林地砍伐或战争焚野都会改变下游礁地的成败。

### 1.6 东部封闭盆地—外海岛弧｜P、东北群岛

- **能量来源**：P 盆地强日照、有限雪融水与昼夜温差凝露，外海岛弧则依赖海洋上涌和火山风化物；两端之间由东向海流交换孢囊、尸体和矿盐。
- **生产者**：P 贴地生长、边缘结出可食种粒的光合籽盘，与其交换糖分和矿盐的地下矿质丝网；岛弧潮间带则由可在浪击后重新黏合的“扣岩叶”占据。
- **主要取食者**：啄开籽盘边缘却不掀毁中心的“环吻地行体”；在岛弧岩沟中过滤扣岩叶繁殖粒的“扇腔伏潮体”；越冬时沿岛链逐段南移的“薄翼滑翔体”。
- **分解者**：P 土层中与矿质丝网竞争残糖的“旱土碎丝”，以及岛弧高潮线下处理漂尸的“盐壳囊群”。盆地分解慢，养分更依赖活体共生网络保留。
- **环境威胁**：P 的盐碱、地震、梯田坍塌与连续旱年；岛弧的风暴浪、火山灰和海流异常。盆地统一种源会放大同一腐败征候，岛链单一补给点则会放大航路中断。
- **季节循环**：P 的籽盘在凉湿季展开，干季伏地收拢并把糖分转入种粒；矿质丝网随短雨脉冲向新土生长。岛弧生产峰值跟随上涌季，滑翔体据风季沿岛逐站迁徙。
- **跨境迁徙**：薄翼滑翔体和漂浮繁殖粒把 P 东岸与东北群岛连接起来，不能因群岛未国家化就视为生态空白；若 P 封港或 A 扩建北岸航站，人类补给线会与同一季节风窗口竞争。

## 2. 四地试写的阅读方式

以下四地均按十项接口书写。人物使用功能性称号，不是永久专名；其作用是检验产权、债务和特权能否落实到个人选择。文化后果只保留因果最强的三项，其他服饰、饮食、信仰与外交留待相应后续单元扩写。

## 3. A｜抬洪粮垫与份水王冠

### 3.1 地图事实与自然瓶颈

A 位于主大陆东北山前，核心聚落靠近多条融雪河分合处，西侧高山隔开 E/I 一侧，北向海岸又是通往东北群岛最近的大陆前站。（F）这里不是稳定湿润平原：雪量、春季升温速度与山崩会共同决定哪条河汊得水。粗砂主槽冲刷太强，真正可连续利用的是坡降较缓、泥底会横向摆动的支汊。（设计 I）

A 的首要瓶颈不是全年“缺水”，而是**能在正确时间抵达正确泥床、且不会把作物连根冲走的缓洪水**。早春洪峰带来细土和矿盐，盛夏却可能断流；旧河道上的堤门、拖索站与仓垫场一旦被新河汊绕开，账面水权便会突然失去物理对象。木材可从上游山前取得，但耐拉湿索所需的长纤维、修闸铁件和外海船材仍是昂贵投入。东北群岛只能提供潜在航路，不能替代本地粮垫与份水秩序。

### 3.2 原创物种卡｜长索抬洪粮垫

| 字段 | 设计 |
|---|---|
| 身体结构 | 由可分离的六角叶盘组成；叶盘上层是薄而耐晒的光合面，下层为充气海绵腔，中央垂下一条富含弹性纤维的长索。索端不是单根根须，而是一束会钻入软泥、横向结网的锚节。叶盘边缘形成富淀粉籽粒，老盘中心另有可食贮块。 |
| 能量取得 | 主要依靠日照固定能量；锚节从新淤泥吸收氮盐与磷盐。农户把人畜残渣经堆沤后埋在锚床下，只能提高局部产量，不能让粮垫脱离洪水更新。 |
| 气体交换 | 上表面的微孔在白昼开启；洪水浑浊或叶面被淹时，海绵腔储存的气体可维持数日。长时间完全没顶会使中心组织缺氧腐坏。 |
| 运动 | 成年体不主动迁移；水位升高时叶盘靠浮力抬离泥面，长索伸直并允许整垫在一定半径内摆动。水位下降时锚节收缩，把叶盘重新牵回泥床。断裂的边盘可随缓流漂到新汊。 |
| 繁殖 | 相邻遗传个体的边缘花穗经风与小型爬行取蜜体传粉后结籽；同时也能靠叶盘断片无性扩张。王家种圃偏爱整齐断片，野生汊口则保留更多有性籽粒。 |
| 生态位 | 占据春汛可淹、夏季会露出部分泥面的低坡支汊；它减缓水速、捕捉细土，为小型涉体和分解群提供栖位，也是 A 最稳定的主粮与淀粉来源。 |
| 选择优势 | 在洪水中抬升而非倒伏，可利用陆生谷物无法承受的摆动河汊；模块受损后仍能由邻盘补空。 |
| 生存代价 | 锚索制造消耗大量纤维与糖，成熟慢；密集克隆共享相近脆弱点，腐斑可沿相接叶盘扩散。深急水会拔垫，长期静水又会让锚床缺氧。 |
| 分布边界 | 只适合淡水、细泥、季节涨落明显且夏季仍有日照的缓汊；砾石主槽、盐水河口、常年深湖和完全干裂的高阶地都无法形成粮田。 |

### 3.3 物种层级与剧情要求

粮垫同时是 A 的地方标志种和生计支柱种。作为标志种，它让河谷呈现“田会浮起、村会转向”的独特景观：屋桥、晒架和步道都围绕叶盘升降留出余量。作为支柱种，它把粮食、锚床、纤维索、河界记录和洪峰预测绑成同一经济系统；粮垫若连续两季衰败，水权贵族的地租、王室仓储、编索户的债务和北岸航运粮票都会同时失效。

它不能成为万能作物。粮垫富含淀粉但蛋白与油脂有限，A 仍需牧养束趾涉体、采集河贝状滤食体并交换盐与金属。粮垫的断片容易运输，却只有落在合适泥床并获得完整锚节群才会成田；因此“偷一片叶就复制财富”在物理上不成立。剧情中任何抗衰败新品系都必须伴随新锚床、新水权或新劳动，而不是让危机自动消失。

### 3.4 三阶段因果史

**第一阶段｜逐汊共作。** 早期家庭随河汊移动，把成熟粮垫拆成若干盘，连同锚泥和纤维索拖到下一处缓水。可主张的是当季照料过的垫群，而不是永久河床。洪水过后，各营地凭旧锚痕、树线和共同记忆重新分配水面；会识别泥床、编结长索与观测雪线的人拥有声望，却尚不能把整条河转化为世袭租源。

**第二阶段｜份水与王冠。** 人口增长后，上游家族修建导洪堤门、固定拖索站并保存多年河图。他们把“先开哪一道门、允许多少叶盘入汊”写成可继承的份水，随后以粮垫抽成供养常备记录者、闸卫和仓场。多个份水家族需要有人在洪峰前统一开门次序，却又不愿让一家永久吞并，于是形成水权贵族选举君主制：君主在若干持大份水的家族中产生，任期以洪水周期和政治承认为准，王冠的实质是调度公共闸索与裁断移动河界。

**第三阶段｜河流脱离账簿。** 长期导流抬高旧汊河床，一次山崩与融雪洪峰在东侧切出新河汊。新汊绕过旧堤门，泥床上又出现能承受当前腐斑的野生粮垫。旧选侯要求封堵新口、焚毁“无谱垫”，以维持份水和王室种圃的权威；新汊移居者、负债编索户和部分下级闸卫则主张把新水列为公汊。自然改道因此直接成为宪制危机。

### 3.5 政体与强势阶级联盟

A 的正式政体是**水权贵族选举君主制**。拥有大额份水、上游堤门与成片母垫的家族组成选举团；君主掌握公共闸卫、王仓和春季最终开门令，却必须在每次大改道后重新取得选举团承认。这个制度并非抽象的贵族爱自由，而是“需要集中调洪、又无法容忍单一家族永久垄断所有上游”的妥协。

强势联盟由大份水家族、王家河图院、闸索守备户和母垫种圃共同构成。河图院证明谁的旧权延伸到哪条新水，种圃决定哪些断片可进入王仓，守备户负责在最短的洪峰窗口执行命令。联盟内部并不稳定：君主希望把新汊登记为王室直辖以扩大财政，旧选侯要按旧份水瓜分，下游小份水家族则担心任何封堵都会先淹没自己。

### 3.6 可垄断资产、租权工具、受压集团与内部裂缝

可垄断资产包括上游导洪口、适合锚节扎根的软泥床、越冬母垫、长纤维浸制池、拖索站和连续河图。租权工具不是笼统“收税”，而是四种具体权利：开门前先扣一份入汊垫；按锚索数量收取床租；只承认带王仓结记的繁殖材料；把修闸、拖垫和夜守洪峰规定为份水附随劳役。欠床租者可以保留劳动工具，却会失去下一年最早入汊次序，继而被迫借高价母垫。

受压最重的是索床编结户、渠道末端的小份水家庭、在新汊搭起浮村却没有旧图依据的移居者，以及采集野生有性籽粒的“散种人”。他们不是同一阶级：编结户可能有专业技能却背负纤维债，小份水家庭有产权却总在洪峰末端得水，新汊移居者有高产泥床却缺法律人格，散种人掌握抗衰败材料却可能被判为破坏王仓秩序。四者是否结盟，将决定危机是改革、内战还是一次被压下的河界重画。

### 3.7 代表角色

- **上汊份水继承人**：继承一座旧堤门的四分之一开门权和选侯家族的旁席资格，但遗产同时附带三年王仓欠粮。新河汊使她的份水快速贬值；若支持封堵可保家族票权，却可能淹死已迁入新汊的姻亲家庭。
- **索床编结领户**：拥有一口浸纤池和带徒资格，按契约必须为王室提供固定长度的洪索；上一季腐斑令订单报废，他以未来两季劳役作抵押借了母垫。其行会知道新汊需要大量新索，却没有在那里开业的合法床籍。
- **野垫藏种人**：没有份水，只持有从废汊收集、已在自家泥箱中越冬的抗衰败有性籽粒。按旧法野籽不得进入王仓，他的财产既可能救活河谷，也足以成为选侯指控新汊聚落“窃取王种”的证物。

### 3.8 可实际触发的剧情危机

春季重划河界前十日，雪线观测显示今年洪峰将早到；与此同时，旧堤门下游连续出现中心发黑的粮垫，新汊野垫却只在边缘留斑。选举团通过临时令：洪峰当夜堵死新汊，并把所有无王仓结记的籽粒投入石灰泥窖。君主私下命河图院寻找把新汊登记为王室公水的依据；两名旧选侯则雇编索户提前切断新汊浮村的系岸绳。

玩家可被卷入三条同时成立的任务：护送藏种人的泥箱穿过闸卫线；在洪峰前找回被选侯隐匿的旧河图，证明新汊曾是公水；或协助领户加固旧堤，却发现封堵会把洪水推向下游小份水村。任何选择都有具体后果：放任新汊会使旧王仓和选侯财政骤降，完全封堵会毁掉抗衰败材料并制造难民，只偷走种子而不取得锚床和水权则只能救少数家庭。

### 3.9 物质矛盾与精神追问

物质矛盾是：公共调洪需要集中命令，然而可继承份水把会移动的河流假定成静止财产；当河流与粮垫共同改变，维持旧秩序本身会摧毁它声称保护的粮源。精神追问由此产生：**合法性究竟来自祖先画下的河界，还是来自让活人继续获得水与食物的能力？** 若每次洪水都能重写世界，人是否仍需要把某条边界称作永恒？

### 3.10 因果最强的三项文化后果

1. **移动聚落**：多数河汊住宅建成可拆梁架，仓台与公共灶固定在高地，睡屋、晒架和小型礼所则随粮垫拖移。一个家庭的“家”由锚索、梁架和共同入汊权组成，不等于一块不动宅地；失去拖索资格比房屋烧毁更接近社会死亡。
2. **份水继承**：继承物以开门次序、锚床容量和母垫份额表示。婚约会交换上游早水与下游宽床，长幼排序随谁能履行夜守洪峰而调整；家族服饰上的结索数量是法律记忆，不是抽象装饰。
3. **春季重划河界仪式**：退冰后，君主、选侯、河图记录者和各汊代表乘浅底拖舟巡河，把新泥床、旧锚痕和淹没树线公开写入当年界册。仪式既纪念河流不可占有，也实际把变化重新纳入租权；因此它可以是和平修宪，也可以在闸卫封河时变成政变现场。

## 4. E｜春汛迁游与王家堤道

### 4.1 地图事实与自然瓶颈

E 位于中北部湖原，辖一座大湖与两座小内陆湖，核心聚落在河湖、林缘和通往 F/D 方向的水陆换载带附近。（F）湖盆可解释为冰川退却留下的低起伏洼地：大湖水面稳定、食物丰富，两座小湖更浅、更暖，春季由漫水草地和细小河道与大湖相连。（设计 I）通往外界的大宗运输需要湖船、短程拖运地与后来修筑的堤道；向东仍受中央山脉阻隔。

E 的自然瓶颈是**短暂而连续的春汛迁徙廊道**。大湖可以供养成年迁游生物，却因深水取食者多、岸浪强而不适合幼体；小湖安全而温暖，却无法全年供养大量成体。连接两者的浅水廊道每年只开放数周，任何高出水面的永久道路、密闭堤坝或连续围网都会把一个完整生命周期切成两个富足却无法自续的半系统。王国的军事与贸易偏偏又依赖全年可走、不会陷入泥原的堤道，因而“修好道路”本身就是长期生态负债。

### 4.2 原创物种卡｜六肢春汛迁游体

| 字段 | 设计 |
|---|---|
| 身体结构 | 躯体低长，具三对分工肢：前肢末端展开成梳状耙，可拨取水面浮生团；中肢为宽掌承重肢，能在软泥上分散重量；后肢侧扁成强力水桨。背部有成对湿腔，腔壁布满细褶；腹侧另有可关闭的短气管口。幼体尾端带一圈吸附瓣。 |
| 能量取得 | 成体在大湖过滤富脂浮生团、刮食浅根席嫩层并吞食小型软体取食者；进入迁徙季前会在腹腔储脂。小湖幼体依靠温暖浅水中的微小漂食体和腐殖颗粒成长。 |
| 气体交换 | 水中主要让湖水流过背部湿腔，离水时关闭外缝、以腹侧气管口换气；湿腔必须保持水膜，因此只能在春雨、浅汛或夜间长距离越陆，干热地面会使其迅速衰竭。 |
| 运动 | 水中以后肢划行、前肢校向；浅滩和草地上以前中两对肢交替抬身，后肢推蹬。成体会沿低频水流震动和祖代气味残留寻找小湖入口，但道路改变后不会“聪明地”自动发现任意涵洞。 |
| 繁殖 | 成体在小湖边缘把成串卵囊压入温暖浅泥，数只个体共同翻泥覆盖。幼体以吸附瓣停在根席背流面，秋季长出完整后肢后随退水沟回到大湖。每只成体通常隔年繁殖，补充速度有限。 |
| 生态位 | 把大湖取得的能量、排泄物与未消化繁殖粒带入小湖，又把小湖成长的幼体带回大湖；它是三个湖盆之间最重要的活体养分泵，也是湖区肉、脂、韧皮和季节劳务的来源。 |
| 选择优势 | 六肢分工使其无需等待深水河道，即可利用短暂漫水草地；小湖繁殖避开大湖深水取食者，成体又能在大湖取得足够能量。 |
| 生存代价 | 湿腔离水时间有限，跨越高燥堤面几乎不可能；繁殖间隔长，对固定迁徙路线依赖强。大湖食物衰退或小湖入口封闭都会导致年龄结构断层。 |
| 分布边界 | 只分布于大湖—浅湿廊道—无大型深水取食者的小湖组合；孤立深湖、常年急河、干燥高地和盐水湖均不能完成其生命周期。 |

### 4.3 物种层级与剧情要求

六肢迁游体同时是地方标志种和生计支柱种。作为标志种，它让 E 的一年以“看见第一道背湿光”而非固定历日进入春季：湖民在堤边守夜、用低鼓提示人群退让，儿童能从湿腔颜色判断个体是否需要回水。作为支柱种，它把大湖捕食、两座小湖育幼、肉脂保存、迁徙引导、道路闸口和王室军粮连接起来；数量衰退会先打击小湖的土壤肥力和季节食物，随后削弱王家道仓与堤道守军。

它不能被当作无限肉兽。繁殖年不能大量捕取返程成体，幼体缺失要数年后才会反映在大湖捕获量上；这正让短期财政与长期再生产发生错位。人工把卵囊搬过堤道只能救少量个体，因为幼体还需要小湖根席、成体气味路径和秋季退水沟。所谓“在王家池里养殖”若没有整个水陆循环，只会成为供宫廷观看的衰弱小群。

### 4.4 三阶段因果史

**第一阶段｜三湖季居。** 早期湖社不把大湖和小湖视为不同领土。家庭冬居大湖高岸，春季沿迁游体开出的湿路进入两座小湖，照看卵泥、修复根席，夏末再随幼体退回。权利附着于具体劳动：谁清过入口、守过卵泥，谁在当季拥有优先采集脂囊、枯皮和退水谷地的资格。湖间道路是低堤、木铺与可拆桥，战争动员弱，却不阻断迁徙。

**第二阶段｜堤道统一。** 大湖核心聚落为了抵抗北方劫掠、把 F 的森林制品和 D 的寒地货稳定运到湖港，修筑高于常年洪面的王家堤道。堤道上的守备、道仓和驿舍让王权能全年征粮、换马、调军，两个小湖领地也因此第一次被持续纳入同一王国。作为交换，王家宣称保护迁游季，授予小湖若干仪式席位；但实际工程只留少数狭门，且开闭首先服从车队与军务。堤道把军事安全和贸易统一带给湖原，也逐步截断养分循环。

**第三阶段｜看不见的空湖。** 连续多年幼体无法返回大湖，小湖根席失去成体翻泥与排泄补充，开始被硬茎浅根席覆盖。道仓仍能用旧储备和从 F 输入的粮食维持繁荣，大湖捕获量也因成体长寿暂未骤降，于是王廷把小湖警告解释为地方拒缴。如今第一批缺失世代已进入本应成熟的年份，迁游队列突然缩短；王国必须在拆开关键堤段、放弃部分全年通行，和继续抽取最后一批成体之间选择。

### 4.5 政体与强势阶级联盟

E 是以大湖核心城和王家堤道为轴的**大湖王国**。君主对湖面本身的控制并不完整，其真正权力来自堤门开闭权、道仓军粮和道路沿线的常备守备。王权以“让三个湖不再受季节分割”为合法性：它能在冬末运粮救灾、在夏季派军，也能使不同湖岸使用相同的道路尺度和货重记法。

强势联盟由王家堤门监、道仓熏制院、堤道守备封户和大湖围栏捕获社组成。堤门监决定迁游窗口，熏制院把肉脂变成可储军粮，守备封户以沿道土地换取驻守，大湖捕获社掌握成体最集中的水面。小湖祭席仍在王廷出现，却多由依赖王家俸粮的人占据。联盟的裂缝在于：守备担心开放低门会让敌军和走私者穿越，道仓需要继续捕取，部分堤门监却已从水位记录看出王国正在耗尽自己的支柱种。

### 4.6 可垄断资产、租权工具、受压集团与内部裂缝

可垄断资产包括全年不淹的堤道路基、迁游狭门、大湖成体围栏、道仓烟室、两座小湖的卵泥入口和记录返程数量的季册。租权工具具体表现为：过堤货物按轮轴与重量纳费；只有持王印者可在大湖设置围栏；小湖家庭必须把规定比例的季获送入熏制院抵偿道路保护；堤道邻村承担填土、铺木与破冰劳役。王家还把“替迁游体开门”列为恩典，而不是承认道路造成的损害。

受压集团彼此利益并不一致。小湖引迁户需要更长开门期；无围栏的浅岸捕获者希望限制大湖特许社；道路填筑户收入依赖工程，却承受溃堤时最先被淹的风险；道仓剖脂工在短期高捕获中有工钱，却最早因原料枯竭失业。大湖普通居民确实从治安、冬粮和市场获益，不能被简单写成王国受害者。真正冲突是收益在当代集中、生态成本在小湖和未来世代累积。

### 4.7 代表角色

- **小湖北湾引迁户**：家族持有一段卵泥入口的习惯照料权，没有王廷地契；她以去年未足额交付的脂囊欠道仓一笔实物债。若今年队列继续缩短，她既还不起债，也会失去证明习惯权的“实际照料”依据。
- **王家堤门副监**：享有狭门通行费的一成终身俸权，升迁条件是保证春季军车准时通过。他保留了十五年迁游数量木筹，知道延迟三日开门足以使大量成体湿腔干裂；公开记录却会让自己的俸权和家族封户一并受审。
- **道仓偿肉妇**：丈夫死于冬季破冰役，她依法继承烟室工位，也继承购置盐料的仓债。她按件取得收入，眼前需要更多捕获量养活孩子；同时她发现今年送来的成体腹腔空瘪，继续熏制只是在把最后的繁殖群变成军粮。

### 4.8 可实际触发的剧情危机

北方道路出现武装队伍，王廷下令把西堤作为军车主线，迁游狭门推迟七日开启。第一批成体已在低洼外聚集，连续两个晴日后湿腔开始失水；小湖北湾的卵泥又因多年缺少翻泥而板结。小湖代表准备夜拆一段堤道，守备则把拆堤视为通敌。与此同时，道仓公布的捕获配额仍按十年前队列计算，特许围栏正堵在大湖入口。

玩家可以运送王家未公开的木筹，证明迁游衰退与开门日有关；也可以寻找一段旧季路，在不毁主堤的前提下开出会淹没两处道仓低院的临时水口。若保护军车，王国短期安全但小湖再失一代；若暴力破堤，迁游得救却可能让冬粮和守军陷入泥原；若只搬运卵囊，少数幼体幸存，导致王廷误以为无需改变制度。危机不能靠一名善良国王发令消失，因为修复廊道意味着重新分配通行费、军务风险和沿道土地。

### 4.9 物质矛盾与精神追问

物质矛盾是：王国靠全年道路把三个湖统一为可征税、可防守的领土，却正是这种固定化切断了让三个湖成为同一生态系统的季节运动。精神追问是：**一个秩序若让当代人免于战争，却把生存成本推给看不见的下一代，它仍是保护吗？** 共同体应由不动的道路连接，还是由每年必须让出的通路连接？

### 4.10 因果最强的三项文化后果

1. **道路—聚落等级**：王道交叉口拥有石基仓、守备院和冬季市场，低级支道只有木铺与季节摊，小湖尽头村则在官方地图上常被缩成“迁游附点”。服饰上的纵向硬条和轮轴印记表示道路俸权；小湖居民故意保留可卷起的软下摆，表明自己仍需踏过浅汛。
2. **季节生计**：同一家庭会在大湖捕获、春季引迁、夏季照卵、秋季采根与冬季修堤间轮换，职业身份不是全年固定。王国要求固定工位和常备守备后，家庭被迫在拿俸与维持完整季节知识之间分裂，代际教育也因此出现“大湖账学”和“小湖水路记忆”两套价值。
3. **小湖身份仪式**：第一批迁游体进入小湖时，引迁户把去年保存的卵泥团投入水口，再以湿掌在儿童肩背印出三对痕迹。仪式实际补充熟悉气味、检查泥质并分配守护段，却被王廷改写为感谢王家开门。小湖人坚持仪式早于王道存在，因此它既是生态维护，也是对王权叙事的温和反证。

## 5. O｜活礁领邦与翻湾巨兽

### 5.1 地图事实与自然瓶颈

O 位于大陆东南的大海湾，弧形山脉向湾内送入多条河流，形成港汊、冲积地和森林坡地；地图城标不代表首都精确位置。（F）海湾并非一块均匀深水：河口细泥持续淤积，潮汐把悬浮物来回推移，少数旧硬底、活礁脊和深槽才可支撑码头与大型船只。（设计 I）湾内港口彼此被山脊、泥滩和曲折水道分隔，天然适合多个领邦而非单一城市完全统治。

O 的瓶颈是**可长期固结的浅海地基**。木桩和孤立石堤都会沉入软泥，只有缓慢生长的矿质礁能把泥滩变成港基与海底地块。洄游巨底体又会周期性翻泥：适度扰动打开深槽、清除窒息旧层，被诱向特定礁脊时却能毁掉数代地基。O 的财富由此建立在“需要扰动、又不能让扰动落到自己的礁上”的矛盾上。

### 5.2 原创物种卡

#### 生计支柱种｜固泥矿礁群

| 字段 | 设计 |
|---|---|
| 身体结构 | 由无数拇指长软体单元组成。每个单元藏在自己沉积的多孔矿筒中，筒口伸出两圈纤毛触冠；相邻矿筒以柔韧活膜相连，逐年形成蜂巢状低礁。老筒死亡后仍保留孔道，新单元会在其上加层。 |
| 能量取得 | 触冠过滤河海交汇处的有机碎屑和微小漂食体；浅水群另与附着在透明活膜中的光合微体交换糖分。它必须同时得到适量泥沙、溶解矿盐和水流，任一过多都会窒息。 |
| 气体交换 | 纤毛使海水持续穿过触冠与体表褶层；低潮时筒口收拢，以孔内残水维持数个时辰。被细泥完全覆盖后无法换气。 |
| 运动 | 成体固着不动，只能缓慢改变触冠方向；幼小定着囊随潮漂流，接触旧礁孔、木桩或裸露石粒后分泌黏盘固定。 |
| 繁殖 | 暖潮初起时，同一礁不同单元把生殖囊释放到水中，结合后形成耐浑浊的漂囊；另可由活膜边缘出芽扩张。漂囊定着窗口短，领邦必须预先设置播礁桩。 |
| 生态位 | 固结湾泥、减弱浪击、为管居碎食群和幼小取食者提供孔隙；人类只采死去外层作港材，活层继续抬高礁面。 |
| 选择优势 | 矿筒既防软泥挤压又让群体在反复淤积中向上生长；模块死亡不致整礁崩溃。 |
| 生存代价 | 生长以年计，不能快速重建；过量淡水、连续厚淤、油脂覆盖或巨兽踩踏会造成大片缺氧。采活层虽能立刻得材，却会让礁体停止自修复。 |
| 分布边界 | 仅适合 O 湾内盐淡交错、潮差可见、底泥下有零散硬粒的浅水带；纯淡水上游、外海强浪、常年深水和无矿盐软泥均不能成礁。 |

#### 地方标志种兼生态工程种｜翻湾巨底体

| 字段 | 设计 |
|---|---|
| 身体结构 | 身体宽扁，成年个体可长于小型驳船；腹面有四对充液承重叶，轮流鼓胀以在软泥上“步行”。前端为横向铲口，能掀开泥层；背部两根可伸缩鳃烟囱保持在浑水上方，尾部有压水囊用于短距离脱困。 |
| 能量取得 | 吞食埋在泥下的富脂根块、衰老礁孔中的碎食群和河口沉积的有机团；人类可用高浓度根脂饼、屠宰残脂和发酵气味制成诱饵。制备足量诱饵需要牺牲大量可食物，不是廉价控制术。 |
| 气体交换 | 水流经背部鳃烟囱进入体内褶腔；翻泥时烟囱可闭合片刻。低氧死湾会迫使其离开，搁浅超过半日则因承重叶受压和褶腔干涸死亡。 |
| 运动 | 平时以腹叶缓慢推泥，遇深槽可压水滑行；它依靠潮流中的脂味和低频地面震动选择取食线。人类只能提高某条路线的吸引力，无法像驾船一样精确指挥个体。 |
| 繁殖 | 成体在外湾较深、底流稳定的沙脊集群配对，雌体隔多年产下少量厚壳育囊并守护一季；幼体数年后才进入内湾。种群恢复很慢。 |
| 生态位 | 翻开缺氧旧泥、打通潮沟、搬运深层矿粒，也会压碎过密老礁；适度扰动维持海湾多样水道，完全排除反而会让浅湾窒息淤死。 |
| 选择优势 | 宽扁承重和鳃烟囱使其能利用其他大型取食者无法进入的软泥；巨大储能让它完成外湾—内湾长迁徙。 |
| 生存代价 | 成熟慢、育囊少、转向迟缓；对连续诱饵和气味污染敏感。被引入死角后可能搁浅，成年个体死亡会使数十里泥湾多年缺少翻动。 |
| 分布边界 | 只在 O 外湾繁殖、内湾季节取食，并沿相邻大陆架短迁；不会穿越深洋、急流河道、淡水上游或封闭内湖。 |

### 5.3 物种层级与剧情要求

固泥矿礁群是明确的生计支柱种：港口、领界、盐池、船坞和部分防浪田都建立在它缓慢生成的硬底上。翻湾巨底体同时是地方标志种和第二支柱：它的背部鳃烟囱、迁徙泥浪与巨大足痕定义 O 的季节景观，也负责浅湾的长期通水。两者不是善恶对立；没有礁群，湾泥不能承载聚落；没有巨底体，老礁与细泥最终封闭水道。

巨底体不是服从命令的战争怪兽。诱导需要数周投饵、合适潮汐和大量脂饼，且只能提高概率。礁材也只可采死筒；生态攻击必须支付食物、隐蔽运输和本地礁失去正常翻泥的代价。

### 5.4 三阶段因果史

**第一阶段｜播礁共湾。** 河口家庭在低潮时把木束和旧矿筒插入软泥，引导漂囊定着，共同维护可停浅舟的硬脊。海底边界随淤积移动，权利来自连续播殖、清孔和让出巨底体通路；剥取活层会造成共同沉降，因而受到邻户制止。

**第二阶段｜礁地领邦。** 成熟礁脊价值超过附近陆田。能保存低潮测线、组织潜手并负担多年播殖的家族，把共同维护转写为世袭海底领地，以港租供养船坞和武装浅船。山脊与曲折港汊阻碍单一王权，若干领邦遂以弱湾议共同处理航标、外敌和迁徙禁令。

**第三阶段｜投饵战争。** 一位次级领主把大量根脂饵沿潮线投向邻邦新礁。巨底体撞开礁脊，既毁港又形成偏向攻击者的深槽。迁徙本有年际摆动，受害者难以举证，各领遂争建秘密饵窖；每家都认为先投饵才安全，全湾却面对巨兽搁浅、繁殖群锐减与礁地互毁。

### 5.5 政体与强势阶级联盟

O 不是统一王国，而是由**礁地世袭领邦**构成的海湾联盟。每一领邦的核心领权来自一片可测、可播、可继承的成熟海底礁地，陆上城镇只是仓、船坞和家族厅所在。湾议没有常备全国官僚，只能以各领邦提供浅船、领港员和死礁材维持共同航道；这解释了 O 能有复杂港建，却难形成 L 式集中动员。

强势联盟由礁领家族、退潮测界院、播礁桩作坊、港基砌造团和季候官组成：它们分别控制图线、定着、采材和巨兽时序。老礁领想限制新播殖，边湾小领需要扩礁；砌造团偏爱采材，播礁者要求保留活层；季候知识既保护全湾，也能被出售为武器。

### 5.6 可垄断资产、租权工具、受压集团与内部裂缝

可垄断资产包括成熟活礁、播礁桩位、低潮测线档、死礁采层、深槽领港权、根脂饵窖和可观测外湾迁徙的岬台。租权工具包括：按船吃水收取过礁领港费；新定着礁必须向上级领主缴“首层”；继承海底边界需由测界院在特定低潮复核并纳费；潜手只能把死筒卖给指定砌造团；湾议禁饵期内的脂饼运输须持领邦封签。法律以保护活礁和迁徙为名，也把生态知识变成许可收入。

受压者各有不同技能与风险：界潜手以身体复核水下界桩，事故后家庭可能失地；播礁养孔户多年才见硬底，却常以未来首层抵债；根块村承担饵料征购，搬砌户在战争中被迫拆毁敌港。外湾候潮社群掌握繁殖地却少有湾议席位。裂缝同时存在于老港与新港、上游饵源与下游礁床、继承法与迁徙共同体之间。

### 5.7 代表角色

- **退潮界潜手**：持有一段祖母留下的终身采死礁权，但继承图只在极低潮可复核；一次巨兽踏损后，邻领声称界桩已不存在。他欠测界院下一次下潜装备费，若接受邻领资助便等于承认对方的边界版本。
- **次礁领继承人**：继承一片尚未完全硬化的新礁和一座装满根脂饼的秘密饵窖，同时继承父辈对港基团的多年材料债。她若销毁诱饵会立即违约，若按原计划投饵则可能把一头育囊雌体引入死角。
- **外湾禁迁候潮者**：家族拥有在岬台观测第一根鳃烟囱的仪式特权，却没有湾议投票权；其报潮报酬由各领邦共同支付。他发现今年进入内湾的成年个体少了一半，公开消息会使港口停工，也可能触发各家争先发动最后一次投饵。

### 5.8 可实际触发的剧情危机

一次大潮后，某领邦新港前的礁脊被巨底体踏开，深槽却恰好转向它的竞争港。受害领在破礁孔中找到带特殊发酵壳的脂饼，湾议准备召开禁饵审判；同日，候潮者报告一头带育囊伤痕的巨底体搁在两领交界泥滩。双方都想先把它引向对方水域，以免承担死亡赔偿和迁徙禁忌。

玩家可护送潜手取得旧界证据、追查脂饼来源，或拆开昂贵活礁为搁浅巨兽放出水道。救兽会使新港失基，保港可能杀死繁殖个体；公开证据会连累饵源村，隐藏则鼓励报复。只要诱饵、港租和水下边界仍属私有，定罪也终止不了竞赛。

### 5.9 物质矛盾与精神追问

物质矛盾是：领邦必须长期排他维护礁地，才能承担播殖和港建成本；这种排他权又给每一家利用共同迁徙系统伤害对手的动机。海湾需要巨底体破旧开新，各领却只愿它经过别人海底。精神追问是：**人能否继承一片仍在生长、移动并依赖全湾循环的海底？** 当没有士兵越界、只有一头被气味诱导的生物留下足痕时，战争从何时开始，罪又应归给谁？

### 5.10 因果最强的三项文化后果

1. **海底领地继承**：遗产以低潮时辰、测线角度、活层厚度和深槽描述。婚约拼接礁脊，丧礼在继承人首次下潜复界后才结束；看不见的海底边界比宅墙更能决定身份。
2. **礁材港建**：房基、码头和防浪墙使用不同死矿筒层，港民能从孔径辨认来源。只采死层本是保礁经验，领主却据此授予砌造特权；宏伟白港也可能暴露过度剥礁留下的债。
3. **迁徙禁忌**：入湾季禁止向潮沟倾倒脂油、敲击低频桩鼓或点燃饵窖，因为气味与震动会改路线。各领须把部分根脂饼封入陆窖，象征放弃操纵；钥匙却由最有能力违禁的人保管。

## 6. P｜种土梯田与一统粮仓

### 6.1 地图事实与自然瓶颈

P 只指最东侧封闭盆地，西部与主大陆之间被弧形高山和少数关口隔开，核心聚落靠近盆地东侧湖泊或河口低地；图上更西的旧 P 标记不参与设定。（F）盆地西、南缘山地截留水汽，内部强日照、风大且降水集中，东向海运虽可能比翻山便宜，却依赖少数出水口和季节锚地。（设计 I）湖泊淡咸、稳定水位和外海港深仍属 O 级，本稿不把它们作为唯一支点。

P 的瓶颈是**能保水、保肥并抵抗风蚀的活土表层**。裸坡遇暴雨会流失，平地细土又会被旱风卷走；没有稳定团粒，灌溉反而造成板结或返盐。籽盘与矿质丝网共同形成“种土”，成熟却需多年。封闭关口促成内部储粮，也让中央错误难获外部纠正。

### 6.2 原创物种卡

#### 地方标志种兼生计支柱种｜贴地光合籽盘

| 字段 | 设计 |
|---|---|
| 身体结构 | 成年体呈贴地圆盘，放射厚叶彼此搭接；浅色绒面反光，低凹中心集露，外缘形成富淀粉与油脂的硬籽。下表面有短根针和数十个丝网交换结口。 |
| 能量取得 | 依靠强日照固定能量；中心露槽和根针利用夜间凝露、短雨与浅渠渗水。它把一部分糖分送入地下结口，换取丝网从矿粒释放的磷、铁与微量盐。 |
| 气体交换 | 主要气孔藏在放射叶的重叠缝内，清晨和傍晚开启，正午闭合以减少失水；暴雨时叶缘上翘排水，若长期浸没则结口腐烂。 |
| 运动 | 固着生长，叶片随湿度缓慢开合：凉湿时展平，干风中收拢。硬籽的吸湿壳会不对称胀缩，推动它滚动数尺，仍需人类压入种土。 |
| 繁殖 | 不同个体中心长出的短穗由夜行传粉体交换粉粒，结成有性硬籽；农户也能切取带结口的幼盘无性繁殖。王仓长期偏爱外形、成熟日一致的幼盘，民间种土保留更多有性籽。 |
| 生态位 | 占据半干旱坡面与梯田表层，遮土、缓冲雨滴并固定细土；籽粒是主粮与油源，老叶可作屋面纤维和补料。 |
| 选择优势 | 贴地形态躲避强风，错峰气孔降低失水，与地下丝网交换使其能在贫瘠矿土持续结籽；外缘受损后中心仍可再生。 |
| 生存代价 | 生长慢、单位高度低，容易被践踏和厚尘覆盖；若结口伙伴不匹配，籽盘看似存活却逐年减产。高度一致的无性盘会对同一种“黄缘枯”表现出相近脆弱性。 |
| 分布边界 | 适合排水良好、昼夜温差大、具有薄活土的半干旱坡地；常年湿地、盐壳平原、密林阴影、高寒山脊和没有矿质丝网的裸砂上均不能形成稳定粮田。 |

#### 共生支柱种｜地下矿质丝网

| 字段 | 设计 |
|---|---|
| 身体结构 | 由半透明中空细丝组成，外层黏附黏土与矿粒，交叉处形成结节；遇籽盘根针时膨大成交换结口。老结节把梯田土锁成抗冲团粒。 |
| 能量取得 | 利用籽盘送入的糖分，也缓慢分解枯叶；末端以弱酸从矿粒释放养分，再输向交换结口。它不能在无活体和残渣的土中凭矿物独生。 |
| 气体交换 | 氧气从疏松土孔扩散进入中空细丝，二氧化碳沿同一路径排出；积水、过度夯实或盐壳封孔会使大片丝网停止活动。 |
| 运动 | 没有整体移动，只有末端沿湿度与糖分梯度缓慢延伸；断裂土团中的活结节可在新梯田接触适合籽盘后重新联网。 |
| 繁殖 | 凉湿季末，部分地下结节形成耐旱粉囊，随土团、工具和小型掘食体搬运；也可通过活丝断段扩展。不同地方丝网与籽盘形成的交换效率不一。 |
| 生态位 | 位于梯田表层至一臂深处，保存矿盐、黏结团粒、分解有限残体，并与籽盘共同形成可继承的活种土。 |
| 选择优势 | 地下环境避开旱风和强光；网络结构允许局部死亡后绕行，也能把短雨获得的水分和养分分散到多个籽盘。 |
| 生存代价 | 依赖宿主糖分与土孔氧气；火烧后再深翻、曝晒或盐浸会杀死活结节，恢复以年计。长期只配对王家籽盘也会缩窄交换对象。 |
| 分布边界 | 只在有机输入、通气孔隙和季节湿润共同存在的盆地细土中稳定；裸岩、移动沙丘、长期水淹层、厚盐壳与反复烧夯的死土中无法维持网络。 |

### 6.3 物种层级与剧情要求

籽盘是 P 最强的视觉标志：田野不是竖立穗浪，而是层层贴地圆盘，干季像收拢的瓦，湿季像铺开的鳞。籽盘与矿质丝网共同组成生计支柱；任何只谈王家种子、不谈配套活土的政策都会失败。“种土”不是神土，而是含有多样籽盘有性籽、活结节、团粒结构和家庭多年管理痕迹的可搬运小块生态系统。

种土不能无限分殖：一篮拆成十篮会降低活结节密度，跨山后也可能不合土粒。救种必须同时保存多种籽粒、活土团、交换经验和数个生长季，偷一只密封匣不能让全国复苏。

### 6.4 三阶段因果史

**第一阶段｜家产种土。** 坡地家庭从旧田切取活土团，随梯田逐块扩展。核心财产不是裸地，而是能互相结口的土层与籽盘。婚姻交换不同坡向的种土，灾后亲族以活团重建塌田；多种成熟日和丝网搭配让收成不整齐，却能分散旱、涝、尘年风险。

**第二阶段｜标准粮仓王国。** 盆地君主修梯田、驿道与分级粮仓，需要可计量、同时成熟的籽盘。繁殖院反复无性扩繁高产幼盘，官吏按统一圆径、含油量和成熟日折税。标准种盘便利赈粮与跨郡调拨，也使王权深入盆地；民间种土则被登记为杂土，私留有性籽须缴仓保。

**第三阶段｜一统种源衰败。** 王家幼盘连续黄缘、空籽，并无法与部分旧丝网结口。官员不知病原，只见杂土田较少同时发黄；繁殖院反而断言杂土“招来土败”，准备焚毁未登记籽粒并深翻旧网。边郡仓吏却已用民种救活官田，证明统一化可能正是脆弱来源；公开证据将追责整套粮仓体系。

### 6.5 政体与强势阶级联盟

P 是**粮仓官僚君主制**。君主的权力不像 A 那样由选侯份水组成，也不像 O 那样分散在海底领邦，而是通过层级粮仓、统一量盘、繁殖材料发放和夯土工程抵达各梯田。封闭地形和少数关口使中央能够检查大宗种粮流动；历次局部旱年中，官仓确实救过许多人，这给“标准即安全、杂异即私乱”的政治观提供真实历史基础。

强势联盟由王家繁殖院、仓衡吏系、梯田夯筑营和山口转粮驿户组成，分别控制种源、税数、墙渠和运输优先权。基层仓吏看见减产却怕推翻账簿可信度；夯筑营担心焚土毁团粒；宫廷繁殖官则无法承认王权制造了全国风险。

### 6.6 可垄断资产、租权工具、受压集团与内部裂缝

可垄断资产包括王家母盘窖、按成熟日分层的官仓、标准量盘和仓印、官渠首口、夯土挡墙工籍、山口驿畜以及登记过的繁殖材料谱册。租权工具具体表现为：领取官渠水必须接受规定幼盘；粮税按标准籽盘折算，杂籽被压低兑价；歉年仓贷以次年种盘和修墙劳役偿还；没有仓印的活土团不得越郡；官仓拥有先购油籽和征用驮篮的权利。所谓统一并非只是一种观念，而是一套把粮、土、人和道路锁进账簿的收益机制。

受压者包括杂种土家庭、不能优先领赈粮的驮篮役户、受烧夯伤害的窑灰工、官渠末端田户和夹在真账与配额间的下仓录数吏。他们不天然同盟：部分家庭靠仓贷度过旱年，窑灰工可能期待焚令工钱，边吏保护民种也可能为建立地方种权。

### 6.7 代表角色

- **种土长女**：按家法继承母系梯田中最老的一篮活土和其中三种成熟日不同的籽粒，但土地本身归父系兄弟分配。她以这篮种土为婚约担保；大焚令若执行，她会同时失去生产资料、婚约信用和祖先身份。
- **下仓录数吏**：持有免除家中一名修墙劳役的书吏特权，代价是每季必须让账面收成符合上仓配额。他发现秘密民种田产量高于官田，已经两次把它记成“旧仓余粮”；第三次若继续造账，整座下仓的赈粮将与实际库存脱节。
- **西梯夯筑役首**：拥有带领百名季役、领取官粮工具的工籍，却欠繁殖院一笔为家乡换取官种的仓贷。他知道焚后深翻会拆散矿质丝网、使挡墙后的土在下一场暴雨中流走；拒绝施工会让全队家庭失去冬粮。

### 6.8 可实际触发的剧情危机

王廷颁下“清土令”：一个月内，所有未登记籽粒和活土团必须交到郡仓，公开焚烧后深翻灰埋；拒交者停止渠水和仓贷。诏令到达时，西部关口因山崩断路，三个上仓的官种盘同时黄缘空籽，东部一座下仓却靠秘密民种田完成收成。繁殖院派出审土使和夯筑营，准备先烧那块“证据田”，以免消息在仓吏网络中扩散。

玩家可分散活土，但分得过小会使结节失活；可窃取实账证明官种先于杂土衰败，却会暴露录数吏伪报；也可拖延深翻，保住丝网却牺牲有性籽。反抗时山口断路使外粮难入，服从则可能迎来更整齐、更大规模的失败。危机在于能否在饥饿迫近时拆开一套曾经有效的机器。

### 6.9 物质矛盾与精神追问

物质矛盾是：统一度量、官仓调拨和标准种盘曾降低局部歉收的死亡，却把全国繁殖材料压缩到相近脆弱性；官僚体系越能执行救荒，也越能同步执行毁种。精神追问是：**保护共同未来是否等于消除一切差异？** 当秩序的可信度建立在“王仓不会错”，承认错误究竟会摧毁国家，还是国家第一次真正承担责任？一篮活种土属于家庭、君主，还是尚未出生却要靠它活下去的人？

### 6.10 因果最强的三项文化后果

1. **夯土梯田世界**：田、路、屋、官仓和防御墙以分层夯土相连，聚落就是梯田的加厚节点。居民从墙裂判断含水和丝网状态；征役既是防灾，也是王权编入劳力的方式。
2. **种土家产传承**：活土团、籽粒组合、坡向知识和交换结口构成不可拆家产。它以篮和土层继承，可脱离土地成为婚约、赎债和流亡资本；烧种等于抹去可繁殖的家系记录。
3. **粮仓仪式**：首批标准籽入仓时，仓衡吏公开校准量盘，君主代表封存“来年之粮”，民众敲壁听仓是否充盈。黄缘年里，官员用夹墙填土制造沉重回声，神圣秩序与伪账遂成为同一动作。
