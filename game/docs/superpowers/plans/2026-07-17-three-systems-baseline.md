# 背包、战斗与 Dialogic 对话系统本轮实现基线

> 状态：已确认，2026-07-17。本文覆盖同主题旧计划中的冲突条款；长期方向未删除，但不得提前进入本轮实现。

## 边界

- 不修改 `assets/`、插件和渲染/物理设置；缺失美术使用现有头像、`ColorRect`、`Label` 或程序绘制占位。
- 不实现诅咒对背包、攻击、防御或闪避的影响。
- 防御/闪避只实现占位时机判定与中央框扩张，不做弹幕、角色移动、冲刺位移、正式攻击动画和粒子。
- Dialogic 仅完成一个流浪者分支样板；不做正式剧情、本地化、任务框架、CutsceneDirector 或磁盘存档。

## 背包

- 每个分类每页 20 种物品，页数不限；`Q/E` 切分类，网格左右越界切页，首末页不循环。
- 每个分类记忆页码与焦点；删除导致空页时回退至上一有效页。
- 所有数量 `<= 0` 的增删请求失败且无副作用；整组丢弃规则不变，已装备物品先卸下。
- 满 HP/MP 时对应恢复物不可使用，直接调用接口也失败且不消耗。
- 装备只作用主角；战斗副本创建时应用装备攻击/防御加成，不永久修改 `GameData` 基础值。
- 名称字号 26 至少可缩到 18，说明字号 17 至少可缩到 13；仍溢出才截断。图标中心误差不超过 1 像素。

## 战斗

- `BattleCommands` 增加 `DEFEND`、`DODGE`；`BattleUnit` 增加 `Stance { ATTACK, DEFEND, DODGE }` 与战斗内 `pending_stance`。
- 姿态从选择时持续到该角色下一次行动开始；期间每次受击均按同一姿态独立判定。
- `RoundStart` 在持续伤害后冻结敌方意图，沿用 Dictionary：`{actor, command, skill, target_side, target_mode, targets}`。
- 冻结的敌对单体目标失效时动作落空；敌对全体动作只作用于存活目标；敌方友方动作保持表现，但失效目标不受效果。
- 防御按 `Z`，闪避按 `Shift`。扩张完成后以 60 Hz 逻辑 tick 判定，第 60 tick 命中；首次正确按键锁定结果。
- tick 57–60 为完美，45–56 为普通成功，更早或未输入为失败。
- 防御完美：0 伤害、0 MP；普通防御：`max(1, ceil(base_damage * 0.33))`，消耗 `min(current_mp, 2, ceil(max_mp * 0.02))`；失败承受全伤。
- 闪避完美：0 伤害并回复 2 MP；普通成功：0 伤害；失败承受全伤。
- 中央框 0.3 秒扩张至 1920×1080 逻辑画布内边距（左右 24、顶部 112、底部 156），命令栏隐藏，其余 HUD 淡至 15%，结算后恢复。
- 攻击姿态也播放占位攻击但不接受防御输入；全体攻击按行动顺序逐个结算。
- 逃跑成功立即停止回合推进并返回荒野；失败才消耗回合。
- 不实现削防、暴击、`parry_buff`、多目标姿态强制联动或诅咒修正。

## Dialogic

- Dialogic 权威：剧情阶段、剧情分支选择、NPC 叙事关系、任务叙事进度。
- `GameData` 权威：背包、装备、队伍、战斗、敌人状态/击败事实、羁绊、诅咒；timeline 只能读取这些事实。
- 本轮变量仅为 `story.flags.met_forest_wanderer = false` 与 `story.branches.forest_wanderer = "unseen"`。
- 保持 `DialogueManager.start(dialogue_id, context)`；管理器仅负责注册表、播放互斥、开始/结束信号和恢复控制，不做 `set_flags`/`bond_add` 回流。
- 流浪者首次交谈提供两个选择并写入 Dialogic 变量；再次交谈按分支变化；`Enemy1` 已击败时通过 `GameData.is_enemy_defeated("Enemy1")` 只读条件显示额外台词。
- 使用 Dialogic 内置 Speaker Textbox、Character 和项目 Style；对话框位于底部约 25%，黑色 80% 透明度，头像缺失可留空或用色块。
- 状态只保证当前运行期间跨场景存在；未来存档以 `Dialogic.get_full_state()` 为集成边界，本轮不实现落盘。

## 验收分辨率

- 主验收：1920×1080。
- 次验收：1280×720。
- 最终主工程控制台必须出现 `[Main] 游戏启动成功`，且无脚本错误和新增警告。
