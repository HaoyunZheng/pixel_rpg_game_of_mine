# Combat VFX sources

本目录只保存战斗实装会使用的 CC0 PNG。未提交原始 ZIP，也未生成或补画中间帧。
源图像素保持不变；项目内只通过 `SpriteFrames` 切帧，并在运行时使用 `modulate`
调整为灰骨白、低饱和冷蓝和暗血红。
