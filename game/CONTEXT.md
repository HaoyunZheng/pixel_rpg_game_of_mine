# 世界地理与文明

本领域描述世界地图上的自然地理、聚落经济与文明关系。术语以“生态约束 → 可排他资产 → 租权集团 → 统治联盟 → 社会冲突 → 文化后果 → 精神追问”的因果链为核心。

## 空间与政治单位

**聚落体**：
以一个核心聚落为组织中心、占据一片可辨疆域的政治—经济单位；A–P 均按聚落体处理，但不预设其一定是主权国家。
_Avoid_: 聚落、国家、文明（在未区分空间层级时）

**核心聚落**：
地图城堡图标所标记的主要人口与组织中心；图标用于定位，不必等同于首都的精确位置。
_Avoid_: 首都（除非设定已明确）

**文明圈**：
共享关键生产技术、制度传统与身份叙事的文化共同体；可包含一个或多个聚落体，也可能横跨疆域线。
_Avoid_: 国家、民族

**疆域线**：
地图上的白色虚线，暂按聚落体的控制范围或争议边界解释；海上的疆域线不自动等同于稳定国界。
_Avoid_: 国境线

## 生态与生物

**生态功能区**：
由能量来源、水热节律和食物网功能共同界定、可以跨越政治边界的生态空间；它不表示共同祖先、文化归属或主权范围。
_Avoid_: 国家生态、文明圈

**地方标志种**：
以原创身体结构适应该地生态，并通过生活方式或地方事件形成辨识度的生物；它不必维持当地的宏观经济。
_Avoid_: 吉祥物、装饰性怪兽

**生计支柱种**：
其数量、分布或繁殖一旦显著改变，便会重组当地主要生产、租权关系或对外关系的原创生物。
_Avoid_: 万能资源、地方标志种（仅承担风格作用时）

## 因果模型

**生计底盘**：
一地在既有技术条件下能够持续供养人口的土地、水源、气候、生物与矿物组合。
_Avoid_: 资源丰富（没有指出具体资源与可利用条件时）

**运输阻抗**：
货物、军队、消息与人口穿越某段空间所付出的综合成本，由距离、坡度、水文、季节、治安与运载方式共同决定。
_Avoid_: 交通不便

**瓶颈资源**：
一个聚落体维持生计或权力时不可替代、却无法在本地稳定取得的投入品。
_Avoid_: 缺资源

**战略通道**：
能够显著降低运输阻抗、且替代路线稀少的河口、海峡、山口、湖岸或陆桥。
_Avoid_: 重要位置

**结构性利益**：
由生计底盘、瓶颈资源和战略通道长期塑造的集体诉求；它不等于统治者一时的个人愿望。
_Avoid_: 国家性格、天生好战

**能力剖面**：
用粮食剩余、能源与材料、运输能力、组织动员、知识保存、对外依赖暴露度、灾害韧性七个维度描述聚落体的能力结构；各维不得相加为单一文明总分。
_Avoid_: 文明等级、综合国力排名

**三阶段因果史**：
以早期生计秩序、排他资产与租权形成、当代统治联盟与危机三个阶段解释社会现状的历史模型。
_Avoid_: 编年史、起源神话

**对外依赖暴露度**：
维持生存或财政所需的关键投入与通道受外部控制、且难以替代的程度；在能力剖面中分数越高，风险越大。
_Avoid_: 开放程度、贸易繁荣度

**超自然节点**：
由特定机构控制、稀有、昂贵且覆盖有限的超自然能力；必须记录作用领域、控制者、财政成本、覆盖尺度与失败风险，不能替代粮食、劳力、燃料、道路或船队。
_Avoid_: 魔法科技树、无限资源

## 权力与叙事

**租权集团**：
凭排他控制土地、水源、种源、通道、设施或知识许可而持续取得收益的社会集团。
_Avoid_: 富人、获益者

**剩余攫取机制**：
统治或租权集团通过地租、税、许可、债息、强制劳役或优先配给转移社会剩余的制度安排。
_Avoid_: 剥削（未说明工具时）、承担成本

**统治结构**：
由政体形式、强势阶级联盟、可垄断资产、租权工具、受压集团与内部裂缝构成的权力组合。
_Avoid_: 核心制度、获益者—承担者

**社会母题**：
由一项物质矛盾及其精神追问共同构成、能够持续生成制度、文化与剧情冲突的主题核心。
_Avoid_: 单一标签、审美口号
