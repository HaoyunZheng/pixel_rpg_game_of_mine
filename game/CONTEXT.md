# 世界地理与文明

本领域描述世界地图上的自然地理、聚落经济与文明关系。术语以“自然条件 → 生计与交换 → 制度与文化 → 地缘行为”的因果链为核心。

## 空间与政治单位

**聚落体**：
以一个核心聚落为组织中心、占据一片可辨疆域的政治—经济单位；A–P 均按聚落体处理，但不预设其一定是主权国家。
_Avoid_: 聚落、国家、文明（在未区分空间层级时）

**核心聚落**：
地图城堡图标所标记的主要人口与组织中心；图标用于定位，不必等同于首都的精确位置。
_Avoid_: 首都（除非设定已明确）

**文明圈**：
共享关键生产技术、制度传统与身份叙事的文化共同体；可包含一个或多个聚落体，也可能横跨疆域线。
_Avoid_: 国家、民族

**疆域线**：
地图上的白色虚线，暂按聚落体的控制范围或争议边界解释；海上的疆域线不自动等同于稳定国界。
_Avoid_: 国境线

## 因果模型

**生计底盘**：
一地在既有技术条件下能够持续供养人口的土地、水源、气候、生物与矿物组合。
_Avoid_: 资源丰富（没有指出具体资源与可利用条件时）

**运输阻抗**：
货物、军队、消息与人口穿越某段空间所付出的综合成本，由距离、坡度、水文、季节、治安与运载方式共同决定。
_Avoid_: 交通不便

**瓶颈资源**：
一个聚落体维持生计或权力时不可替代、却无法在本地稳定取得的投入品。
_Avoid_: 缺资源

**战略通道**：
能够显著降低运输阻抗、且替代路线稀少的河口、海峡、山口、湖岸或陆桥。
_Avoid_: 重要位置

**结构性利益**：
由生计底盘、瓶颈资源和战略通道长期塑造的集体诉求；它不等于统治者一时的个人愿望。
_Avoid_: 国家性格、天生好战
