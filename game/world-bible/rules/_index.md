# 世界规则基线

## 空间与时代

- 世界按东西约 7,000–9,000 公里、南北约 5,000–7,000 公里的中型尺度推演。
- 人类是本世界原生居民，与地球不存在历史联系。
- 常态物质技术为不均衡的成熟中世纪：铁器、畜力、帆船、河运和水力可用；火药、工业能源与大众印刷不普及。
- 当代处于武装冷和平。全面战争尚未爆发，扩军、封锁、宣传与代理冲突已经能够改变日常生产。

## 超自然

- 可受机构和高明智者部分掌握的操作，与坚定信仰或强烈情感中偶发的奇迹来自同一现象，但不同传统对它有互斥解释。
- 受控操作只能提高有限条件下的成功概率；奇迹不能按命令重演。
- 超自然的固定成本与最大作用尺度尚未确立。在该问题解决前，它不得成为稳定粮源、工业能源、大众医疗、常备军种、运输体系或国家能力评分依据。

## 社会与叙事

- “自由如何借敌人定义自身”是可能反复出现的母题之一，不是唯一母题；世界不替读者裁决权力或人性的最终答案，也不为题材发展预设方向。
- 民族数量不预设。只有迁徙、征服、登记、殖民或共同抗争真正把人群政治化时才建立民族；本轮只强制审查 L 的军国主义排外与 G 的南寒岛殖民。
- 属灵、帝皇、自然、学问、唯物只是分析精神生活时的粗分类，不是五套固定宗教，不与文明或超自然真理一一对应。
- 内容面向成年受众，可以深入战争、殖民、酷刑、饥荒、歧视、天灾和权力斗争；制度后果与身体恐怖同样重要，但都必须服务人物选择。

## 命名与游戏接口

- A–P 档案完成前只使用代号和功能称号。永久国名、民族名、语言名和机构名在共享历史建立后统一生成。
- 主角所属机构和首个可玩区域保持开放；不得从当前森林 Demo 反推世界正典。
