# C｜呢绒商栈国

## 1. 摘要与地图证据

C 是西北大岛上的羊毛呢绒与转口贸易之国。岛内河谷牧羊、山地蓄林、沿海航运；世袭王与河谷贵族会议共治内陆，港口城市持宪章自治。众多商行（类企业组织）在港口竞争，两家最大的巨头分掌南北航线：一家独营通往寒海火岛（[B](b.md)）的硫磺专线，另一家经营对主大陆的呢绒与转口贸易。C 曾在大陆西岸拥有一座商栈城，关税一度占王室收入近三分之一；与大陆的战争失败后，商栈城被夺，关税骤减。如今大陆防备 C，却仍与 C 贸易；商人们一边攥紧硫磺与呢绒两条命脉，一边谋划重新打进大陆市场。岛上最显眼的景色，是白帆船队、呢绒晾架，和滩涂上退潮才露出半截的老港断柱。

### 事实（F）

- C 是西北大岛，中西部有山，核心聚落在东部河谷，整体地理近似不列颠群岛。
- C—B 与 C—主大陆之间存在西北航道。
- 位于北温带、西风带内。

### 推断与本条提案（I／Proposed）

- 西坡迎风湿润（林地、泥炭、牧地），东部低地较干、适合耕作；河流短而急，天然深水港分布不均。
- 生计底盘为谷物、牧羊、山地林木、泥炭、石材与近海渔业；可能的金属矿待定。
- 岛内翻山成本高于沿海航运；东岸最容易联系主大陆。
- 羊毛呢绒是 C 的出口支柱；优质船材、沥青等航海材料部分依赖进口。
- 政体为世袭王与河谷贵族会议共治，港口持宪章自治，特许商行经营外贸。

### 开放项（O）

洋流方向与航线季节窗口、人口精确规模、具体矿种、商栈城的位置与战争细节、与大陆具体哪个聚落体贸易均未确认。

## 2. 自然瓶颈与生态位置

C 的底盘由三块拼成。西部迎风坡湿润多雨，森林与泥炭覆盖，山间谷地放牧；中部山脊把水汽挡在东侧；东部河谷较干，是主要的耕作与聚落地带。河流自山脊向海岸短促下泄，落差大、泥沙急，天然深水港只在少数河口与避风岬角形成——港口的位置是否背风、是否抗淤，决定一座城镇的命运。

羊业是 C 的支柱，却不靠单一草场：河谷草甸供夏秋放牧，山地林间与泥炭坡供春冬转场；羊毛品质随牧地不同而分等，河谷毛细软、山地毛粗韧，混纺是当地工艺的看家本领。呢绒加工依赖水源（漂洗、染色）与燃料（煮染用柴、泥炭）。

C 最缺的不是粮食，而是造船材料。山地林产多为建材与柴薪，适合做桅杆、龙骨、甲板的长直硬木不多，沥青、大张帆布与优质铁件也需进口。这使 C 的船队规模被进口能力卡住——船材断供，船队就要缩水。

西北航道把 C 与两端连接：西北向通往 B（寒海火山岛），暖季可航，B 的硫磺与海兽皮是 C 的命脉输入；东南向通往主大陆西岸，是呢绒与转口货物的去向。两条航线都受季节风暴与海雾制约，冬季基本封航。

## 3. 形成史与后续影响

### 第一阶段：河谷、羊群与沿岸村社

最早的居民在东部河谷垦田、养羊，山地与海岸散布小村。河谷贵族以庄园收租，沿岸村社靠渔与短途运输为生；羊毛在岛内织成粗呢自用，多余的沿岛内航线换盐、铁与木材。这一时期的秩序是分散的：河谷看庄园，海岸看潮水，彼此不统属。

- **直接后果**：人口沿河谷与海岸分布，山脊以西的林区人烟稀少。
- **制度后果**：河谷贵族掌握土地与羊毛；沿海村社掌握船与航路；两类权力互不隶属。
- **跨代后果**：岛上的"内陆"与"沿海"从此是两种生活节奏，为后来的商行与贵族之分埋下根。

### 第二阶段：羊毛出口、商行与商栈城

大陆对呢绒的需求出现后（买家为大陆西岸的沿岸政权与织造城镇，未锁定具体聚落体），C 的羊毛与粗呢开始外销。王室发现贸易税比地租好收，便向港口发特许状：港口城市以船役与关税换自治权，商行持牌经营外贸。港口随之分化——老港率先淤塞，货物改走新发现的深水港，商行搬迁，权力随港口转移；旧港的断柱从此立在滩涂上。

两家商行在竞争中做大。第一家拿下王室对 B 航线的专营授权，用谷物、木材与粗铁换回硫磺，又把硫磺配成漂洗液处理呢绒——漂白、防虫、柔化，成品比大陆同行更白更软，出口因此压过对手。第二家经营对大陆的销售网络，把呢绒与转口硫磺送进大陆的织造城与药房，在大陆西岸建起商栈城，囤货、定价、收税都在那里。商栈城一度成为 C 在大陆的门面，关税占王室收入近三分之一。

- **直接后果**：羊毛从庄园自用变成出口商品，牧羊、剪毛、纺织、染整各环节都有人以此为业。
- **制度后果**：特许制固定下来——王室发牌、商行经营、港口自治；两家巨头的航线版图成型。
- **跨代后果**：账本、契约与信誉成为岛上最受尊敬的东西；"做买卖"从副业变成一种值得托付身份的事业。

### 第三阶段：商栈丧失与当代拉锯

与大陆的战争爆发（对手为大陆西岸某政权，未锁定字母），C 战败，商栈城被夺，驻栈人员撤回国。关税收入骤减，王室财政收紧；呢绒出口失去大陆据点，只能经第三方代理转手，利润被层层压薄。战争还烧毁过港口街区，海蚀随后又吞掉老港残躯——两道伤疤叠在一起。

停战后，大陆防备 C：商行在大陆的驻点受限，代理权被卡，商人们被当作"想夺回商栈城的人"提防。但贸易仍在继续——大陆需要 C 的呢绒与硫磺，C 需要大陆的市场与船材。当代的 C 处在一场没有爆发的拉锯里：两家巨头互相争航线与信贷；商人们谋划重新打进大陆市场、开辟新航路；王与贵族想收回港口的部分权力、提高特许年费；港口的中小商行与船工则夹在中间，看巨头眼色过活。

## 4. 生产、产权与分配

### 牧羊与羊毛

河谷庄园与山地牧场共同供毛。剪毛在春末，羊毛按品质分等打包，由毛商收购。河谷贵族控制大部分牧地与剪毛工，羊毛收购多用赊账：毛商先赊给牧民盐、布与工具，剪毛季再以羊毛抵账，牧民的售价由毛商记账说了算。贵族与毛商之间则以庄园为单位谈年约，价格逐年重议。

### 呢绒加工

呢绒场集中在港口外围与河谷下游，靠水而设。工序为纺线、织布、缩绒、漂洗、染色：缩绒工在热水与皂液中踩布收紧；漂洗工用硫磺配的溶液处理呢绒——这是 C 的独门工艺，漂白、防虫、柔化，配方只有掌握 B 硫磺线的商行保有，染坊用茜草、靛蓝、姜黄等植物染料上色，颜色以靛蓝与素白为主。织工与漂洗工按件计酬，旺季赶工、淡季歇业，先领料后结钱，欠账挂在商行账上，工钱常被压到只够糊口。

### 航运与商行

商行是 C 外贸的基本单位：一家商行通常有一处商栈、若干账房、几条船与一批代理，经营一条或几条航线。持牌商行须向王室缴纳特许年费与关税；领航员在深水港外带船进港，收费是港口的行规。船工与水手按航次领酬，风险自负——沉船、劫掠与海雾都算在船工头上，商行只赔货不赔人。两大巨头之外，中小商行经营岛间航线、次等呢绒与散货，船材与码头泊位的优先权常被巨头截走。

### 出口与进口

出口：呢绒（主打，北销给 B 的粗呢与南销大陆的细呢）、谷物与木材（给 B）、转口硫磺（给大陆的医药与炼金买家）。进口：优质船材、沥青、帆布、铁件，以及大陆的奢侈品与少量药材。贸易顺差集中在两家巨头手里；王室的关税与特许年费随贸易量浮动——商栈城丧失后，这块收入明显变薄。

## 5. 政权、合法性与行政边界

C 是世袭王与河谷贵族会议共治的王国。王掌特许状发放、关税征收、对外和战与最高裁判；贵族会议掌河谷庄园的地租、羊毛年约与地方治安；港口城市持宪章自治，城市法庭、码头税与商行注册由港城自己管理。三者相互需要：王没有贵族会议便收不齐地租与兵役，没有港口便收不到关税；贵族离不开商行把羊毛变成现钱；商行离不开王的特许与仲裁，也离不开贵族的羊毛。

行政覆盖沿河谷王城、港口与几条主要航路最强。王廷能核对的，是关税账本、特许状名册与商行年审；离开王城一日路程与港口航线，命令靠庄园管事与港城官员转述。王廷没有常设税吏下乡，也没有大众统计。

军队在战时由各庄园出役兵、港口出船与水手，组成以商船武装为骨干的舰队。C 没有庞大常备军；海上力量平时是武装商船与护航队，战时才聚成舰队。与大陆战争的失败，使王廷对"靠商船打仗"的可靠性心存疑虑，却无力另建王家舰队。

### 三股统治与执行联盟

- **王室—河谷贵族联盟**：王、贵族会议、庄园管事与关税书吏。它靠地租与关税过活，希望收回港口部分权力、提高特许年费，也最在意"商栈城是否还能夺回"。
- **两家巨头联盟**：两大商行及其账房、船主与大陆代理。它要扩特许、少缴税、自由开辟新航线，彼此之间又为航线与信贷相争。
- **港口中小商行与船工联盟**：中小商行、领航员、水手、织工与漂洗工。它依赖港口秩序与巨头分剩的活计，常被船材配额、泊位优先与压价卡住喉咙，是涨税与扩权时最先被转嫁代价的一方。

三个联盟在同一王国内讨价还价——争特许、争关税、争商栈城的话事权。目前还没有人把分歧推向刀兵。

## 6. 垄断与代价

| 排他资产 | 控制者 | 租权工具 | 主要承担者 |
|---|---|---|---|
| 特许状与航线专营权 | 王、关税书吏 | 特许年费、B 线专营授权、新航线审批 | 持牌商行、被拒发牌的中小商行 |
| B 硫磺专线 | 巨头一 | 专营授权、硫磺定价、漂洗配方保密 | B 岛采集工、依赖硫磺的同行 |
| 大陆销售网络与代理 | 巨头二 | 商栈代理契约、大陆人脉与口岸关系 | 被排除在外的中小商行 |
| 深水港、船坞与领航知识 | 港城自治机构、领航员行会 | 入港引航费、泊位优先、船材配额 | 外船、新船东、中小船主 |
| 河谷羊毛收购网 | 河谷贵族、毛商 | 赊账链、庄园年约、羊毛分等定价 | 牧民、剪毛工 |
| 硫磺漂洗配方 | 巨头一 | 工艺保密、染坊供应 | 织工、漂洗工、受制于配方的染坊 |

真正被攫取的剩余集中在三处。一是**织工与船工的劳动**：按件计酬与航次酬制让旺季利润几乎全部流向商行与船东，淡季与海难的亏损却由工人自己扛。二是**牧民的价格差**：赊账链把牧民锁死在毛商的账上，羊毛按毛商记账的等级与价格结算，丰年未必多收、歉年照样抵债。三是**B 的硫磺差**：B 的采集工用命换来的硫磺，在 C 手里既当漂洗原料又转手大陆，B 居民长期不知道这批黄石头在别处的价钱。

## 7. 聚落形态与基础设施

核心聚落（东部河谷的城堡锚点）是王城：石砌王廷、贵族邸宅、庄园粮仓与羊毛仓沿河排列，王廷门前立着拴马桩，议事在贵族会议厅。它是政治中心，却不是贸易中心。

贸易中心在港口。深水港码头边，白帆船队卸货装货，蓝白相间的仓房山墙沿着岸线排开：墙刷白、梁柱漆靛蓝，门楣挂黑木招牌配铜字。码头有秤与验货台，关税吏持牌核对；商行街的账房窗口摊着蜡封账本，学徒就着天光抄账。港区外围是呢绒场：木架晾着成卷白呢绒，雾里看像一片云；硫磺漂洗池冒着淡烟，染坊门口挂着茜草红与靛蓝的碎布样。白石灯塔立在岬角，夜里用灯语报航向，守塔人由港城发饷。

滩涂上立着老港的断柱——退潮时露出半截，涨潮没入水中。老港淤塞后，商行搬去深水港，柱基与废船坞留在这里，被海蚀慢慢啃。港区西侧还有一排空置的商栈：那是大陆商栈城母行的旧址，战争后业务萎缩，门板钉死，账房锁着。两道废墟是 C 的两道伤疤——一道被海吞，一道被夺走。

## 8. 信仰与精神生活（草案，待作者最后确认）

C 没有祭司，没有神庙，也没有一套教义。秩序感来自两处：账本与海。

内陆与商行街信奉的是**契约伦理**：账目清楚、字据立稳、承诺兑现，是一个人最体面的样子。商行学徒入行先学记账与行规；违约者被行会除名，其名在商行街的账房之间流传，比受罚更可怕。新船下水、年度结账、开航前夜，都有世俗仪式——酒洒船头、账本过秤、招牌重漆，祷词是一句老话："账平了，路就顺。"

沿海信奉的是**航海规矩**：灯塔要有人守，雾里不抢道，遇险船先救人不救货。领航员在船工眼里近乎半神——他们记得每一处暗礁与每一股潮，嘴里念着避讳，脚下数着浪。风暴后，家属在码头点灯等船；沉船者的名字被刻进港口的名册墙，每年祭日，船队停航一天，让海记着人。

这两套规矩没有神学，也不互相打架：账本管人怎么活，海管人怎么死。唯一接近"共同信仰"的，是商栈城丧失的记忆——每年祭日前后，老人们在码头讲起大陆那边的商栈，讲关税怎么从厚变薄，讲"总有一天要回去"。这话有人当真，有人当酒话，但人人都听过。

## 9. 身份、迁徙与民族化

C 的身份边界是职业与地域，尚未形成政治化民族。内陆人看自己是河谷庄园的；港城人看自己是商行或船行的；渔民与织工各有圈子。商行、港口、河谷之间常有摩擦，但都以利益与行规解决，没人把它们上升为"我们"与"他们"的对抗。

商栈城丧失提供了共同叙事的材料——"失市"的记忆、撤栈的老兵、空置的母行——却还没有一个组织、一面旗帜或一场运动把它变成政治身份。被夺的商栈城在不少人口中是"该夺回的东西"，但夺回与否、靠谁夺回，各说各话。

## 10. 立场与具体人物

### 结构位置

- **控制者**：王与贵族会议握特许与关税；两家巨头握航线、信贷与配方。控制者彼此也互斗——王想收权，巨头想自治，两巨头之间争市场。
- **执行者**：关税吏核对货与牌；港城官判码头纠纷；商行管事定收购价、发工钱、签代理约。执行者两头为难——既替制度收钱，也替制度背骂名。
- **受益者**：两家巨头、分到贸易红利的河谷贵族支系、持牌商行与领航员行会。
- **成本承担者**：织工与漂洗工（按件计酬、淡季歇业）、船工与水手（海难自担）、牧民（赊账链锁价）、被挤出泊位与船材配额的中小商行、以及 B 岛上按 C 定价卖硫磺的采集工。
- **反对者**：中小商行想组盟对抗巨头；织工想谈工价；部分河谷贵族不满商行把羊毛价压得太狠；还有少数人主张"对 B 改公平贸易、对大陆先稳住"——他们未必反对王国，只是不接受某个具体的盘剥。

### 人物一：关税书吏——替王国数钱的人

五十来岁，在王廷关税房做了一辈子账。他记得商栈城还在时关税账本有多厚，如今只剩一半。他每天核对货单、贴封条、盖章，最清楚哪些商行偷漏、哪些船实际没装够。他忠于王廷，却也知道王廷靠巨头养着——他写年报时，把巨头漏税的数字故意写得含糊，因为上面没人真想看到。他是制度的执行者，也是制度里最知道真相又最无力的人。

### 人物二：B 线商行的主事——两头都熟的生意人

四十岁上下，巨头一派驻 B 航线的常客，每年暖季带船队去[寒海火岛](b.md)收硫磺。他认得岛上每个人的名字，会给孩子带糖，会留盐给识者——这些善意是真的，他对那座岛有复杂感情。但生意优先也是真的：他知道硫磺离开 B 之后值多少，知道漂洗配方离不开它，也知道"有些事必须干净利落"。某位 B 长老的"意外"与他有关；他做完之后照常上岸，照常笑，照常收硫磺。他心里有裂痕，但船照开。

### 人物三：大陆线商行的管事——想打回去的人

巨头二的管事，负责与大陆打交道。商栈城丢失后，他亲手安排撤栈，看着账房锁门。如今他经第三方代理把呢绒卖进大陆，利润被压薄，还要忍受大陆口岸官吏的盘问与防备。他最想做的事，是重建一个大陆据点；他最怕的，是又一次战争把刚搭起的线烧断。他比任何人都清楚"被防备"是什么滋味——他每次过海，都被当成可能夺回商栈城的人。

### 人物四：中小商行主——挤在缝隙里

经营一条岛间航线与次等呢绒。他拿不到 B 线的货，也进不了大陆的大口岸，泊位要排巨头后面，船材配额被截，信贷利率比巨头高。他暗中联络几家同行，想组一个"小商行盟"向王廷请愿：要么放开航线，要么压巨头的特许。他也怕——巨头一句话，他的货就可能压在码头卖不出去。

### 人物五：漂洗工——命脉边上的苦力

在硫磺漂洗池边干活，整天闻着淡烟，双手被药水泡得发白。他做的是 C 最值钱工序里的苦活：呢绒白不白、软不软，一半靠他的手。可他按件拿钱，旺季累死、淡季断顿，商行随时能换人。他听过"配方保密"的说法，知道自己离那个秘密最近，却一分好处也分不到。他是 C 繁荣的最底层证据——呢绒的白，有一半是他在池边泡出来的。

## 11. 文化与日常后果

- **时间观**：一年以剪毛季（春末）、出航季（夏秋）与封航季（冬）为节律；商行以账期为界，牧民以剪毛季为界，船工以航次为界。人们说"上一账期""下一船期"，而不是月份。
- **家庭与继承**：庄园与牧地由贵族长嗣继承；商行靠学徒制传艺，入伙凭本事与股本，两巨头之家的子弟要进自家账房从头学起。织工与船工的家庭世代传手艺，孩子从小帮忙。
- **教育**：账房学徒学记账、算利、验货；领航员学徒背暗礁与潮位；织工学徒认线认染。识字集中在账房、关税房与商行，不形成大众教育。
- **服饰**：呢绒是身份的语言——灰呢常服人人可穿，细呢礼服是体面人的，染成靛蓝或茜红的彩呢只有富户与商行主穿；船工穿粗呢短打，漂洗工系围腰。港口人看袖口与衣料，就知道对方在行里站哪一格。
- **饮食**：河谷粮加羊肉、沿海鱼加盐；商行街有大陆来的香料与酒，是"体面生意"的排场。封航季靠腌肉、干鱼与存粮过冬。
- **禁忌与措辞**："断契"指违约与除名，是商人最重的骂；"过栈"指经第三方转手，带贬义；"失市"指商栈城丧失的旧事。开航前不说翻船、沉货之类的话；账房不赊账给除名者。"守塔"既指守灯塔，也暗指守着一段没指望的念想。
- **建筑审美**：蓝白仓房、黑木铜字招牌、白石灯塔构成港口的视觉语言；王城是石砌灰墙，贵族邸宅挂羊毛纹饰；呢绒场的晾架与漂洗池是港区最醒目的"露天招牌"。

## 12. 玩家可见表象

核心体验是观察一场多线拉锯：巨头互争、商人向外争、王商相制，织工与船工在最底层被卷着走。玩家没有战场可进，能介入的是关税房、商行账房、码头与漂洗池边。

### 熟悉锚点

- 码头蓝白仓房、黑木铜字招牌，秤与验货台前排队的货队。
- 呢绒晾架上的白呢绒在雾里像云，硫磺漂洗池冒着淡烟。
- 王城石砌灰墙、拴马桩，贵族会议厅的议事。
- 灯塔夜里一闪一闪的灯语。

### 可推断变体

- 关税房贴出新的特许年费名目，中小商行主在码头骂骂咧咧。
- 巨头一的新船下水，酒洒船头；同一天，小商行主的货在码头压着等泊位。
- 大陆代理带回的口信让巨头二管事锁了几天门——"口岸又查得严了"。
- 漂洗工在池边讨工钱，账房学徒摊手，说"账期还没到"。
- 祭日那天，船队停航，老人们在码头讲商栈城，滩涂断柱在退潮里露出来。

### 暂不可尽知

- 硫磺离开 B 之后值多少、漂洗配方怎么配（B 岛居民不知道，玩家可逐步查证）。
- 商栈城到底因何失守、有没有内应（撤栈老兵各说各话）。
- 两家巨头的真实家底与王室私账的缺口。
- 谁是"夺回商栈城"真会动手的人，谁只是嘴上说说。

### 可触发危机

商栈城的话题随时可能点燃：大陆某次加税或封锁，让巨头二的代理线断了；王廷为补关税缺口提高特许年费，中小商行联合请愿；巨头一为压价对 B 收紧收购，B 岛那边的"意外"旧账被翻出来；或织工在旺季发动停工，商行街第一次见识"账平不了"的后果。玩家的选择——帮谁查账、替谁传话、给谁出货——会把拉锯推向谈判、妥协或第一次动手。

## 13. 待联网接口

- **B（已建，Proposed）**：巨头一持专营授权年年来收硫磺与海兽皮，供谷物、木材与粗铁；硫磺大部用于 C 呢绒漂洗，多余转口大陆。C 档案为 B 档案中的"垄断收购""C 商人常客""长老意外"提供了制度背景。B 岛采集工是 C 成本承担链的最末端之一。
- **大陆呢绒与硫磺买家（功能画像）**：需要细呢的织造城镇与需要硫磺的医药/炼金买家；它们防备 C，却离不开 C 的货。具体聚落体待后续匹配。
- **夺走商栈城的大陆势力（功能画像）**：大陆西岸某政权，停战但未归还商栈城，限制 C 商行驻点；其动机、规模与对 C 的进一步要求待建立。
- **船材、沥青、帆布与铁件供方（功能画像）**：能稳定提供航海材料的大陆/沿岸聚落体；断供会直接压缩 C 的船队规模。
- **潜在竞争者（功能画像）**：同样产呢绒或经营西北航线的沿岸社会；若出现，会压薄 C 呢绒与转口的利润。

## 14. 现实机制注释

- **借鉴机制**：中世纪羊毛贸易与关税养王权（王财政从地租转向贸易税）；加莱式大陆商栈（海外据点 + 贸易垄断 + 关税占比极高 + 最终丧失）；五港同盟式"船役换特权"与港口淤塞兴替（次线）；羊毛禁运外交（原料垄断作武器的历史与代价）。
- **成立条件**：羊毛呢绒体积小、价值高，撑得起远洋贸易；关税占财政大头需要港口集中与王室有簿记能力；商栈城需要大陆方面愿意让外国商行驻留。
- **本世界改造**：硫磺漂洗呢绒是本世界独有的产业咬合（B 硫磺线 = C 呢绒命脉）；两家巨头分掌南北线的结构；"失市"记忆作为共同叙事而非民族主义。
- **不可照搬**：不复制任何现实国家的王朝史、议会制度、宗教与民族叙事；商栈城丧失是经济与主权伤痕，不套用英国与法国的战争进程。

## 15. 开放问题与一致性检查

- 洋流方向与两条航线的季节窗口长度（决定船期与风险，暂按"暖季可航、冬季封航"处理）。
- 商栈城在大陆西岸的具体位置、失守经过与停战条件（功能画像，不锁字母）。
- 两家巨头的组织形态细节（家族合伙？合股？）与王室特许的具体条款。
- 精神生活草案（第 8 节）待作者最后确认。
- 人口精确规模与具体矿种。
- 与大陆具体哪个聚落体贸易、战争对象是谁——留待各自档案建立。
- 本档案与 B 档案一致：C 商船、垄断收购、C 商人常客、B 长老"意外"均可从 C 制度得到解释。
- 本档案不复制 A 的祭司团、驿传、逐海刑或利维坦设定；不与废止试写中的旧 C 内容衔接。
