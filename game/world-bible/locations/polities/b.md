# B｜寒海火岛

## 1. 摘要与地图证据

B 是地图最西北角的寒带火山离岛，一两百人分属五个同源渔民家族，住在沿海避风湾与山腰地热区。他们原本靠近海渔猎自给；C 的商船发现岛上硫磺后，每年暖季来收一次硫磺，留下谷物与木材。公产按人头均分，贸易收益归采集者自留，双轨并行。年轻采集工在年度大集上见过 C 的生活方式，内心开始动摇；老渔民则警惕 C 的船只越靠越近。一位暗中核对硫磺价钱的长老死于一场被认作意外的山石事故，只有一名青年不信。岛上没有王权、没有军队、没有祭司——只有五家族长投票、识者带路、长老占卜。火山是它的出口，也是悬在所有人头顶的灾。

### 事实（F）

- 位于地图最西北角，是寒带离岛，岛上有火山，平地稀少。
- 距最近的 C 隔海，C—B 之间存在西北航道。
- 黑色火山地表；处于北寒带。
- 火山喷发、火山灰、毒气、海啸是 B 的季节性灾害。

### 推断与本条提案（I／Proposed）

- 火山土局部肥沃，但寒冷、强风、坡陡限制耕地；地热可延长局部生长季。
- 生计底盘为近海渔猎、海兽、硫磺、火山岩与地热盐业。
- 冷季海面结冰且风暴频繁，与外界基本隔绝；暖季有约四至六个月的航行窗口。
- 粮食与木材是瓶颈：本土无成林，木材依赖漂木与 C 进口。

### 开放项（O）

火山活跃程度、核心聚落精确位置（图上 B 未见明显城堡图标）、海兽具体种类、与 A 及其它聚落体的联系均未确认。

## 2. 自然瓶颈与生态位置

B 所在的火山岛自然环境（火山地貌、海岸、海洋、气候、地热系统与灾害）详见[西北火山岛](../../ecology/northwest-volcanic-island.md)。本节只写人对这片自然的使用方式与瓶颈。

海面是食物来源：暖季近海鱼群与海兽（海豹、海象为主，鲸为偶发大猎）提供全年主要蛋白；捕猎与渔获晒干、熏制后储入仓库，供冷季食用。海兽的皮制衣、油点灯、骨制工具，几乎覆盖了岛上除金属外的所有材料缺口。

地热是唯一稳定的热源与种植条件。温泉与蒸汽口沿山腰分布：温泉可沐浴、洗衣、煮盐；蒸汽口上方的烘干房处理鱼干与皮毛；少数被地热烘暖的坡地种着耐寒蔬菜与块根，产量不大，但冷季里这些绿叶是稀缺的。温泉田与烘干房由公产管理，家家轮流使用。

火山本身是双面资产。硫磺沿火山口与裂缝持续析出，几乎取之不尽；但采集要深入烟区，灼伤、呛咳、崩塌随时可能夺命。火山的另一面是喷发、火山灰、毒气与海啸——预警靠识者多年的经验判断（地热温度、冒烟浓度、动物行为、地震频率），加上长老占卜，而占卜大部分时候并不灵验。

燃料不靠砍柴：地热供暖，漂木与海兽油补充。淡水来自融雪、温泉与雨季蓄积，旱季紧张。B 没有自己的森林，造船与修屋的木材几乎全部来自 C 的进口货与偶尔漂到岸边的浮木——这让 C 的船队对 B 而言不只是商人，还是木材来源。

## 3. 形成史与多阶后果

### 第一阶段：五家族的渔猎时代

最早抵达避风海湾的渔民来自何方已不可考。他们在海湾两侧建立窝棚，靠近海渔猎自给，人数少、联系紧，慢慢形成五个彼此通婚的家族。渔区按家族划分，谁家在哪片海面下网、哪个礁石群归谁家猎海兽，由口头传统确认；歉年则各家按长老议定的份额互相接济。这一时期的秩序只有两样东西：渔区的口头规矩，和长辈传下的避讳。

- **直接后果**：五家族靠海兽与鱼获养活了一两百人，人口规模长期被渔获量压住。
- **制度后果**：公产均分成为默认——渔获交公、按户分配，个人几乎不留私产；只有从海里捡回的漂木、海兽油这类"无主之物"归拾得者。
- **跨代后果**：人人以渔猎为生，航海与海兽猎杀的知识沉淀在家族口传里；长辈因为记得最多，成为自然权威。

### 第二阶段：C 商船与硫磺的进入

某年暖季，一艘 C 的商船为避风暴停靠 B 的海湾。船员认出火山口的硫磺，用一小袋谷物换走了一筐——这笔交易对双方都划算。此后 C 的船每年暖季来一次，用谷物、木材、粗铁换硫磺与海兽皮。B 居民起初只当硫磺是"火山口旁边顺手捡的黄石头"，能换东西就好；C 商人从不说明硫磺在别处的价钱。

贸易带来了第一批想致富的年轻人。他们发现采集硫磺换来的谷物与铁器，比打一年渔还多，于是从渔猎转向采集。采集需要进烟区、爬陡坡，老一辈不愿意干，年轻人却觉得这是"离 C 的生活更近一步"的路。采集工从各家族的青年里冒出来，渐渐成了岛上第二个职业群体，但他们的家族归属没变——他们仍是五家族的子弟。

- **直接后果**：B 第一次有了外部收入，粮食与木材不再完全依赖本地。
- **制度后果**：双轨经济成形——公产（渔获、温泉田、盐）仍均分，但贸易收益归采集者自留。谁出海、谁采集，谁就保有那部分所得。
- **跨代后果**：岛上一代人被分成两种活法：守着渔猎与均分的老一辈，和抱着硫磺想富起来的年轻人。两边都认为自己有理。

### 第三阶段：当代的静默拉锯

如今 B 处在一个没有爆发的平衡里：五家族长照旧投票议事，年轻人照旧采集，C 的船照旧年年来。公产均分让没人饿死，贸易自留让少数人攒下铁器与好船；老渔民眼看年轻人越来越少下海，担心渔猎传统断掉，也担心 C 的船某天不再只是来收硫磺。年轻人则觉得老辈守着均分是守着穷。

## 4. 生产、产权与分配

### 渔猎

海兽与近海鱼是公产：猎获与渔获交公，由各家族长老按户均分。渔区归家族，捕鱼权世代相传；猎海兽的礁石群有固定的季节轮换，避免各家争抢。歉年由长老会按当年总获重新分配，谁家也不至于饿死，但谁也别想靠渔猎致富。

### 硫磺采集

硫磺区位于火山口与裂缝附近，属公产，但采集由个人完成。愿意采集的人（基本是年轻人）自己下烟区、自己装筐、自己背下山；采得的硫磺由采集者自留，卖给 C 商船后收益归自己。家族长老不抽成，也不禁止——这是双轨制里最让老一辈皱眉的部分：同样在岛上，打渔的交公，挖硫磺的自留。

采集的代价由采集者独自承担：烟区灼伤、呛咳、缺氧、塌方、迷路。每年都有人带着灼疤回来，偶尔有人没能回来。识者掌握火山口的路，谁要进烟区，得先请识者领路或听一段避讳——避讳挡不住毒气，但老规矩这么传着。

### 地热与盐

温泉田、烘干房、煮盐锅都是公产，按户轮流使用。盐按户分配，烘干房先紧着公家的鱼干，再排私人的皮毛。地热温室坡地由长老会划片，各家轮流种，收成归各家。

### 分配总则

公产均分保生存，贸易自留养野心。对外卖出的只有硫磺与海兽皮；买进来的只有谷物、木材、粗铁与少数成衣。账目不立文书——五家族长各记各的，识者的刻符记着每年 C 船来去的日子与大致数量。

## 5. 政权、合法性与行政边界

B 没有君主，没有官府，没有军队。五家族长各代表一族，集体投票处理公事：分配歉年渔获、划定温泉轮用、决定是否接受 C 商船提出的新交易条件、组织避难。表决按多数，年长族长的意见权重更高——资历在渔猎社会里本身就是资格。

识者不是官员。识者是岛上记得最多的人（通常一至三位），管祭祀、管火山口领路、管调解邻里与家族间的破裂酒礼。他们的话有人听，但他们不投票、不裁决；当五家族投票僵住时，识者的话能左右风向，但那靠的是威望，不是权力。

行政能力受制于人口与交通：一两百人分居海湾与山腰两处，暖季靠步行小径与舢板往来，冷季几乎各自为政。公事多在海湾渔村的长老屋里议，山腰采集地的人暖季下山参加大集与议事，冷季则少下山。王廷式的"统治"在这里不存在，存在的只是"商量"。

合法性来自三处：公产均分的传统（谁也不能让自家人饿死）、长辈的经验（记得最久的说话算数）、以及活下来的事实（这座火山岛至今有人住着，本身就是规矩成立的证明）。

## 6. 排他资产与剩余攫取

| 排他资产 | 控制者 | 租权工具 | 主要承担者 |
|---|---|---|---|
| 家族渔区与猎兽礁群 | 五家族 | 口头渔区传统、季节轮换 | 各家渔民 |
| 硫磺区与火山口路径 | 公产，识者领路 | 领路许可、避讳规矩 | 采集工（年轻人） |
| 温泉田、烘干房、煮盐锅 | 公产 | 按户轮用、长老划片 | 全体居民 |
| 避风海湾与船坞 | 五家族共有 | 停靠次序、修船互助 | 渔民与采集工 |
| C 贸易渠道 | 五家族长老会 | 接受/拒绝交易条件 | 全体（受益与风险并存） |

真正被攫取的剩余集中在两处。一是**采集工的劳动**：他们冒生命危险采出的硫磺，在 C 手里被转手卖出高得多的价钱，而采集者只拿到 C 商船当场付的那点谷物与铁器；B 居民在很长一段时间里并不清楚硫磺离开本岛后的价值。二是**公产均分的隐性税**：老渔民年年交渔获养着全岛，年轻人却把贸易所得收进自己口袋——老一辈觉得这是年轻人占了公产传统的便宜，年轻人觉得这是自己拿命换的。

## 7. 聚落形态与基础设施

B 有两处常年聚落与一处应急去处。

**沿海渔村**：坐落在避风海湾的卵石滩上，面向 C 的方向。十几座火山岩墙体、漂木梁、海兽皮顶的屋子沿滩排开；滩头立着晒鱼架与翻扣的舢板，湾内有一处浅船坞和一间公家仓库。长老屋是村里最大的石屋，议事、祭祀、招待 C 商人都在这。大集时，海湾里泊着 C 的商船，滩上摆开硫磺筐、兽皮捆与谷物袋。

**山腰采集地**：沿温泉与蒸汽口分布，距渔村约半日脚程。硫磺工棚、烘干房、煮盐锅、几片地热温室坡地散在蒸汽雾里；采集工旺季住这，淡季回渔村。这里常闻硫磺的呛味，冬天比渔村暖，因为地热就在脚底下。

**高处洞穴**：喷发预警后，居民按梯度转移——沿海渔村先撤到山腰采集地，采集地再撤到更高的岩洞。洞内常年备着干粮、水囊、皮毛与火种；洞壁刻着历代逃亡的日子。这是一两百年人唯一共同的应急设施，平时只有识者每季上去查看一次。

建筑材料几乎全靠火山岩与漂木：墙体是黑石，梁柱是 C 运来的木材与偶尔漂来的浮木，屋顶覆海兽皮再压石块。金属极少，粗铁多做成鱼钩、刀尖与硫磺筐的扣件，由铁器集中的几户人家租借使用。

## 8. 信仰与精神生活

B 没有庙，没有神像，没有祭司。精神生活围绕几位识者与一年里的几个日子展开。

识者主持的祭祀祈求四件事：渔猎丰收、出海平安、人丁兴旺、火山不要喷发。祭品是头茬渔获、海兽油与自酿的发酵汁；祭地在海湾的石堆或山腰的蒸汽口旁。没有经文，祭词是口传的几句老话，各家孩子从小听熟。

避讳是信仰的另一半：出海前不说不吉利的话；火山口附近不指指点点；刮南风烟大的日子不上山；死者的名字在当年内不被提起。这些规矩没有神学解释，理由是"老辈这么传的"，但每一条都对应着一件真实的事故——某年谁在哪片海没了，某次烟大时谁在山口丢了命。

火山预警是信仰与经验交界的模糊地带：识者凭经验判断，长老占卜问询，两者互相补充。占卜大部分时候不灵——求雨不下、问凶不凶，答案常是"再等等看"。居民并不因此不信占卜，他们把占卜当成"向火山问路"：问不出准话，但问一问才安心。识者则相反，他们信自己的眼睛多过信占卜，嘴里说着避讳，脚下数着烟的变化。

**B 的精神生活没有机构、没有教义、没有分裂**；它镶嵌在渔汛、大集、喷发预警与生老病死里，是活着的习惯，不是信仰的体系。

## 9. 身份、迁徙与民族化

B 的认同边界是"五家族之一"与"岛上的人"，两者都不构成政治化民族。五家族共享祖先记忆与渔猎传统，但彼此以渔区、婚配与口音区分；对 C 来人，全体居民共用"外人"这个词，并不细分 C 的商人与 C 的船员。

年轻采集工与老渔民的代际张力是岛上最明显的身份分化，但它尚未沉淀成民族或阶级：采集工仍是各家族子弟，他们的财富与见识让老一辈侧目，却没人因此被逐出家族。**B 没有迁徙、征服、登记或殖民的历史，因此没有形成政治化民族的因果链**——岛上只有两个职业群体在互相打量。

## 10. 道德位置与具体人物

### 结构位置

- **控制者**：五家族长。他们守公产均分、议定交易条件、组织避难；多数长老偏保守，个别见过世面的更倾向多与 C 做生意。真正的知情者在他们之外——识者与已故的某位长老。
- **执行者**：识者（领路、祭祀、调解、记刻符）与采集工中的领头者。识者两头为难——既怕火山出事，又怕年轻人出事；采集工头领着年轻人下烟区，赚着最多的贸易收益，也担着最重的人命责任。
- **受益者**：采集硫磺的年轻人（自留收益）、C 商人（转手利润）、少数攒下铁器好船的家族。
- **成本承担者**：下烟区的采集工（灼伤、缺氧、塌方、迷路）、老渔民（渔获交公养全岛，眼见年轻人不下海）、偶尔被火山吞没的整户人家。
- **反对者**：部分老渔民主张"少跟 C 来往"；识者以沉默对抗外来者对岛的吞噬；已故的某位长老曾暗中调查硫磺价格真相；一名年轻采集工正沿着他的脚步，怀着愤怒重新走上同一条路。

### 人物一：识者——见过世面的悲观者

五十岁上下，认得火山口每一条路，记得历代喷发的日子。他年轻时随 C 商船去过大陆，见过更大的势力如何对待资源产地——比 C 更贪婪、更不在乎岛上人的死活。回到岛上后，他成为领路人，领着采集工上山，嘴里念着避讳，脚下记着烟与温度。他知道硫磺离开 B 之后的价值远不止 C 付的价钱；他也知道这个真相一旦传开，引来的是比 C 更可怕的掠夺者。所以他沉默。他主持祭祀、偷偷用刻符记录地热变化、把那笔账烂在肚子里。他自认为是在保护这座岛，但他也是岛上最清楚"真相被掩盖"的人——他既是守门人，也是蒙蔽者。他的矛盾在于：他越保护，越明白自己正在替谁遮掩。

### 人物二：已故的某位长老——暗中调查的牺牲者

五家族中的一位长老，刚死于一场"意外"：他在采集地附近跌入碎石沟，被冲下山的石堆掩埋，多数人认为是失足。只有少数人记得，他生前常在私下询问 C 商人硫磺的价、打听大陆的行情，用刻符记下一笔笔 C 商船运走的数量——那本刻符笔记至今没人找到。他暗中相信硫磺的价钱不对，正在一步步验证，然后"意外"发生了。他的死被当作事故入土，公产均分的账上少了一个爱较真的名字，C 商船第二年照常靠岸。他的调查线断了，但有一个年轻人捡到了它。

### 人物三：采集工主角——从逐利青年到愤怒的斗士

二十岁出头，五家族里最早上山的一批年轻人之一。他在大集上见过 C 商人的穿着与谈吐，回去后把渔网挂进了仓库。他采硫磺、攒铁器、学 C 商人说话的口音，做梦都想有艘自己的船。他与那位已故长老非常亲密——长老教他认山、记刻符，也常在他面前念叨硫磺的价钱"不对"。长老死后，别人信是失足，他不信：他记得长老上山那天不该去那条沟，也记得那天 C 商船的船工在采集地附近出现过。他是岛上唯一怀疑"意外"的人。随着他顺着长老的刻符与遗物追下去，他会发现硫磺的真相，也会从"想富"变成"要个公道"——然后，他将在愤怒与勇气中，第一次在家族会议上说出"我们要自己定硫磺的价"。

### 人物四：老族长——传统的人格化

七十多岁，管着家族渔区四十多年。他的身份感全部来自渔猎与公产均分：他是那个记得每户该分多少鱼、谁家船坏该先修谁家的人。他见过 C 商船从一艘变成每年固定来，也见过自家孙子把渔网换成硫磺筐。他投票支持均分、支持给采集工留贸易所得——他认这个理，但夜里常对着空着的船位叹气。硫磺让他感到的不是愤怒，而是被时代抛弃的恐惧：年轻人觉得均分是穷，觉得他是旧规矩的化石。他也许会是最后一个坚持"打渔是岛的本分"的族长，而他自己也知道这一点。

### 人物五：C 商人常客——复杂矛盾的生意人

四十岁上下，是 C 派驻 B 硫磺线的常客，每年大集时带着船队靠岸。他认得岛上每个人的名字，会给老族长的孙子带一块大陆的糖，会在风暴季留一袋盐给识者——这些善意是真的，他对这座岛有复杂的感情。但生意优先也是真的：他知道硫磺在大陆的行情，知道转手利润是多少，也知道"有些事必须干净利落"。那位长老的"意外"，与他的船队有关；他做完之后照常上岸，照常笑，照常收硫磺。他心里的裂痕只有他自己知道：他喜欢岛上的人，也正在一点点毁掉他们。

## 11. 文化与日常后果

- **时间观**：一年以两个节律为准——暖季的渔汛与年度大集，冷季的隔绝与储备清点。日子按"上次大集"与"下次大集"计算；冷季漫长，人们用刻符数着岩壁上的记号等暖季。
- **家庭与继承**：渔区与猎兽礁群按家族继承；硫磺筐与采集装备是采集工的私产，可传给子弟。年轻一代的职业选择成为家庭内部争吵的来源——父亲让儿子下海，儿子想上山。
- **教育与知识**：渔猎技艺靠口传与跟随长辈出海习得；刻符记账只有识者掌握，普通居民不识字。硫磺的采集技巧（看烟、辨缝、扎烟布）由老采集工带新人，一代传一代，不落文字。
- **饮食**：海兽肉与鱼干为主，地热温室的蔬菜是冷季的稀罕物；C 的谷物做成粥饭，是"富人家"才常吃的。发酵汁（用海兽油与根茎酿的烈物）用于祭祀与待客。
- **服饰**：海兽皮缝制的衣裤耐寒耐磨，采集工的烟布护面罩是山上才用的装备；少数攒了钱的人穿 C 的粗布衣，在岛上显得扎眼。
- **禁忌与措辞**：出海前忌说不吉之言；火山口附近忌指认；死者名当年不提。"上山"在岛上既指去采集地，也暗指"去冒险"；"守着船"指老派渔民，带一丝长辈的赞许与年轻人的不屑。
- **建筑审美**：火山岩黑墙、漂木梁、兽皮顶是基调；烟囱口与蒸汽口的位置决定屋子朝向；有地热的地段屋子密，没地热的地段只有仓库。岛上没有装饰性建筑，只有"活下来用得着的"与"给火山看的"——石堆祭台是后者。

## 12. 玩家可见表象

核心体验是观察一场静默的拉锯：五家族、两种活法、一个岛。玩家没有王廷可进、没有军队可调，能介入的是长老会议、识者的领路与年轻人的野心。

### 熟悉锚点

- 海湾卵石滩上翻扣的舢板与晒鱼架，家家户户的兽皮屋顶压着石块。
- 长老屋里围坐的五位族长，烟斗与刻符，议事的规矩比决议多。
- 识者带人上山的背影，腰间挂着烟布与绳索，嘴里念着避讳。
- 公家仓库的均分账——没有文书，靠各家代表当面点。

### 可推断变体

- 大集后，有年轻人站在 C 商船边上看他们卸货，眼神里有东西在变。
- 采集工三五成群下山，脸上带着烟灰，筐里是黄澄澄的硫磺；老渔民在滩头望着，不说什么。
- 长老会上有人提议"硫磺的价是不是该涨"，被老族长一句"价是 C 定的"顶回去。
- 识者独自在山口记刻符，被问到占卜灵不灵时，只说"火山自己知道"。
- 冷季里，岩洞避难所的石壁刻着密密麻麻的记号，最旧的已看不清。

### 暂不可尽知

- 硫磺离开 B 之后值多少钱、被卖到哪里（居民不知道，玩家可逐步查证）。
- 占卜在剧情高潮时的那一次"奇迹"是什么、为何应验。
- 火山何时喷发、喷发后 B 是否还能存在。
- C 的船队对 B 的善意有几分真、几分是生意。

### 可触发危机

火山预警或 C 商船带来的消息可能打破平衡：一次冒烟异常让全岛进入避难演练；C 商船某年没来（或来得比往年早）让谷物库存见底；那名不信"意外"的青年顺着已故长老的刻符追下去，第一次在家族会议上说出"我们要自己定硫磺的价"——这个念头一旦说出口，五家族要投票决定的就不只是价钱，还有要不要背着一个看不见的买家，走一条没人走过的路。

## 13. 待联网接口

- **C（主要贸易伙伴）**：谷物、木材、粗铁换硫磺与海兽皮；年度大集；C 垄断收购且 B 初期不知硫磺转手价值。需要 C 档案确认其人口、港口与对 B 的具体政策。
- **硫磺转口买家（功能画像）**：需要硫磺用于医药、仪式与炼金材料的大陆聚落体；愿意支付远高于 B 所得价格的中间商。未锁定具体字母。
- **木材与粗铁供方（功能画像）**：能稳定提供造船与修屋木材、粗铁的沿岸聚落体；断供会直接压缩 B 的造船与修补能力。
- **潜在竞争者（功能画像）**：同样产硫磺的其它火山/温泉聚落体；若存在，会压低 B 硫磺的稀缺价值。
- **A 及东北方向（开放）**：B 与 A 隔海相望但分属不同航路系统，当前不预锁任何关系。

## 14. 轻度现实机制注释

- **借鉴机制**：中世纪硫磺贸易（医药、羊毛漂白、仪式用硫）；冰岛/法罗群岛式寒带渔猎自给；岛民对火山的地热利用与梯度避难。
- **成立条件**：硫磺体积小、价值高，支撑得起一年一度的远航收购；渔猎公产均分需要人口极少且渔获可预期。
- **本世界改造**：公有均分与贸易自留的双轨制度；经验预警与占卜并行；"大陆魔法原料"作为硫磺的仪式/炼金用途（不构成超自然能量源，符合规则基线）。
- **不可照搬**：不复制任何现实岛国的政体、宗教或民族叙事；C 的"攫取转手利润"是经济关系，不是殖民关系。

## 15. 开放问题与一致性检查

- 火山活跃程度（休眠／周期活跃／频发）——决定硫磺产业的稳定性与避难制度的强度。
- 核心聚落精确位置：图上 B 未见明显城堡图标，暂以"避风海湾渔村"为功能定位。
- 海兽具体种类与渔获节律；鲸猎是否偶发。
- 占卜"奇迹"的具体形式（留待剧情）。
- 玩家如何到达 B（首个可玩区域保持开放，不从玩法反推）。
- 与 A、D、E 等北方聚落体的航路联系（当前只写功能画像，不预锁字母关系）。
- 本档案与地理 Spec 的 B 节一致；不复制 A 的驿传、逐海刑、利维坦或祭司团设定。
