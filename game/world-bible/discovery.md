# 世界圣经导航

本目录是本轮 A–P 世界观的持久知识库。它保存作者来源、已批准事实、待审提案、推测、废止内容和显式冲突；仓库内其它旧世界观文档不自动成为这里的事实。

## 正典权威

- 作者拥有最终裁定权。
- 原始地图与笔记见 [`sources/manifest.md`](sources/manifest.md)。
- 地图事实及地理推断的已批准解释见 [`世界地图自然地理说明 Spec`](../docs/superpowers/specs/2026-08-17-world-map-geography-spec.md)。
- 因果方法与知识库边界见 [`ADR-0001`](../docs/adr/0001-causal-ecology-worldbuilding.md) 和 [`ADR-0002`](../docs/adr/0002-world-bible-canon-governance.md)。
- 统一领域词汇只在 [`CONTEXT.md`](../CONTEXT.md) 维护。
- 所有条目的当前状态见 [`canon-status.md`](canon-status.md)。

发生冲突时，不按“新文件优先”或“篇幅更长优先”处理：先登记冲突，再由作者裁定。`Established` 条目不能被低状态内容覆盖。

## 当前阶段

世界圣经基础已经建立；A 聚落体及其东北风暴海、风暴利维坦和王家祭司团已形成 Proposed 条目，等待作者审阅。B–P 尚未开始。旧 A/E/O/P 试写已废止，不得作为素材池或隐含前提。

1. 来源清单与地图。
2. 地理 Spec 与世界规则。
3. 当前聚落体档案。
4. 它引用的生态、物种、民族、机构和事件。
5. 关系网与共享历史。
