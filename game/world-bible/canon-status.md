# 正典状态总表

状态含义：

- **Established**：作者已经批准，可作为后续条目的事实。
- **Proposed**：等待作者审阅，可自由修改，不能支撑更高状态结论。

- **Deprecated**：已被明确放弃，仅保留历史记录，禁止进入新设定。
- **Contradicted**：与其它事实冲突，裁定前不得继续扩写。
