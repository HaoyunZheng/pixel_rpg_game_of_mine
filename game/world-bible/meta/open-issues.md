# 开放问题

| 问题 | 当前边界 | 解锁条件 |
|---|---|---|
| 超自然的固定成本与最大尺度 | 不得成为稳定经济、医疗、运输、军种或能力评分依据 | 单独审阅超自然规则并形成正典决定 |
| 主角所属机构 | 不从当前玩法占位推断 | A–P 与跨地机构完成后决定 |
| 首个可玩区域 | 当前森林 Demo 不绑定 A–P | 世界关系网与主角结构位置完成后决定 |
| 永久国名、民族名、语言名和机构名 | 只用 A–P 与功能称号 | A–P 及共享历史完成后统一命名 |
| 地图未确认的港口、矿种、河流方向与人口尺度 | 沿用地理 Spec 的 O 级状态 | 新地图或作者裁定 |
